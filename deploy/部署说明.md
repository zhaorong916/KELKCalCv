# KELKCalCv 服务器部署说明

> 主仓库：https://gitee.com/KELKzhao/kelkcalcv（备份：github.com/zhaorong916/KELKCalCv）
> 文档更新：2026-10-20

## 1. 系统概述

KELKCalCv 是调节阀 Cv 计算与噪音分析系统（B/S 架构）：

- **后端**：Python 3.10+ / FastAPI + uvicorn，监听 8000 端口
- **前端**：Vue 3 构建产物，由后端 `backend/static` 目录直接托管（无需单独部署前端）
- **数据库**：SQL Server（192.168.1.112:1433，库名 KELKCalCv）
- **访问地址**：`http://<服务器IP>:8000`，接口文档 `http://<服务器IP>:8000/docs`

## 2. 环境要求

| 组件 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / Windows Server 2016+ | 部署脚本基于 cmd 批处理 |
| Python | 3.10 及以上 | 安装时勾选 "Add Python to PATH" |
| Git | 任意较新版本 | 用于克隆与更新代码 |
| ODBC Driver 17 | 必装 | pyodbc 连接 SQL Server 的驱动 |
| 网络 | 可达 SQL Server 1433 端口；可达 gitee.com | 防火墙放行 |
| 端口 | 8000 未被占用 | 对外访问需放行防火墙入站规则 |

ODBC Driver 17 下载：<https://learn.microsoft.com/zh-cn/sql/connect/odbc/download-odbc-driver-for-sql-server>

## 3. 方式一：一键部署（推荐）

1. 将部署包解压到服务器任意目录（如 `D:\KELKCalCv-deploy`）
2. 双击运行 `bootstrap.bat`，脚本自动完成：
   - 检查 Git / Python / ODBC 驱动
   - 从 Gitee 克隆仓库到 `kelkcalcv\` 子目录
   - 自动生成 `backend\.env` 并打开记事本供填写
   - 确认后调用 `deploy\start-server.bat` 启动服务
3. 在记事本中填入真实的 `DB_HOST` / `DB_USER` / `DB_PASSWORD` / `SECRET_KEY` 并保存
4. 回到脚本窗口按 **Y** 启动，浏览器访问 <http://localhost:8000>

> 若私有仓库克隆时要求登录，输入 Gitee 账号（或个人访问令牌）即可，凭据由 Git 凭据管理器缓存，之后 `update.bat` 无需重复输入。

## 4. 方式二：手动部署

1. 安装 Python 3.10+、Git、ODBC Driver 17
2. 克隆仓库：

   ```bat
   git clone https://gitee.com/KELKzhao/kelkcalcv.git
   cd kelkcalcv
   ```

3. 生成配置文件：

   ```bat
   copy backend\.env.example backend\.env
   notepad backend\.env
   ```

4. 双击 `deploy\start-server.bat` 启动（首次运行自动创建 venv 并安装依赖）
5. 浏览器访问 <http://localhost:8000>

## 5. 配置文件说明（backend\.env）

| 配置项 | 说明 | 示例 |
|---|---|---|
| DB_HOST | SQL Server 地址 | 192.168.1.112 |
| DB_PORT | 端口 | 1433 |
| DB_NAME | 数据库名 | KELKCalCv |
| DB_USER | 登录用户 | Sa |
| DB_PASSWORD | 登录密码 | （必填，严禁入仓库） |
| SECRET_KEY | JWT 签名密钥 | 任意长随机串 |
| BACKEND_CORS_ORIGINS | 允许的前端源 | 默认即可 |

完整清单见仓库 `backend\.env.example`（已脱敏为占位符）。

## 6. 日常运维

| 操作 | 方式 |
|---|---|
| 停止服务 | 运行 `deploy\stop-server.bat` |
| 更新代码 | 运行 `deploy\update.bat`（git pull + 依赖同步，**不覆盖 .env**） |
| 重启服务 | 运行 `deploy\start-server.bat` |

推荐更新顺序：**stop → update → start**。

## 7. 开机自启（可选）

使用 Windows 任务计划程序（`taskschd.msc`）：

1. 创建基本任务 → 触发器选"计算机启动时"
2. 操作：启动程序 `D:\...\kelkcalcv\deploy\start-server.bat`
3. "起始于"填写该 bat 所在目录 `D:\...\kelkcalcv\deploy`

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 启动报 pyodbc/ODBC 相关错误 | 未安装 ODBC Driver 17，见第 2 节下载链接 |
| 连接数据库失败 | 检查 `.env` 四项 `DB_*` 配置；在服务器上测试 1433 端口连通性 |
| pip 安装慢/超时 | 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 8000 端口被占用 | 运行 `stop-server.bat` 清理；或 `netstat -ano \| findstr :8000` 找到 PID 后 `taskkill /F /PID <pid>` |
| 局域网其他电脑无法访问 | 放行防火墙入站：`netsh advfirewall firewall add rule name="KELKCalCv" dir=in action=allow protocol=TCP localport=8000` |
| git pull 报冲突 | 服务器上不应手动改代码；`git stash` 后重试 update |
| 启动报数据库配置缺失 | `backend\.env` 未创建或未填写，见第 4/5 节 |
| 批处理中文乱码 | 脚本必须保持 UTF-8 with BOM 编码（头部 `chcp 65001`），不要用记事本另存为 ANSI |

## 9. 安全须知

- `backend\.env` 含真实密码，已被 `.gitignore` 排除，**严禁**提交或拷贝入仓库
- `.env.example` 仅为占位符模板；任何文档不得写入真实凭据（项目红线，见 `docs/项目规则.md`）
- 数据库口令疑似泄露时，立即在 SQL Server 上轮换：`ALTER LOGIN Sa WITH PASSWORD = '<新密码>';`，并同步更新各服务器 `.env`
