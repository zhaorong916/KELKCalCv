## 任务 2.1 规则 seed 数据准备

**新建文件**：`docs/selection_rules_v1.json`（规则清单）、`backend/seed_selection_rules.py`（幂等入库脚本）

### 规则清单结构
JSON 为规则对象数组，字段严格对齐 `SelectionRuleBase`：
`rule_code / rule_name / category / target_series / condition_expr / condition_op / action / action_payload / priority / source_ref / is_active`

- `rule_code` 命名：`R-{CATEGORY 缩写}-{SERIES 或 GLOBAL}-{序号}`，如 `R-SCOPE-GLOBAL-001`、`R-CON-GC210-001`
- `priority`：scope=10 / constraint=20 / preference=30 / post_filter=40（按 category 固定）
- `condition_expr`：受限 JSON 字典，键取自方案 §2.1 白名单（见 2.3）
- `target_series`：具体系列码，全局规则用 `*`
- `source_ref`：溯源，格式 `GC120_210_structured_data.json:general_data.bonnet` / `方案§4.2C` 等

### 规则构成（合计 ~100 条）

| category | 数量 | 来源与要点 |
|---|---|---|
| scope | ~40 | ①阀型决策树（`media`+`valve_action`→排除角行程/开关/自力式家族，来自方案 §4.2A 与 `valve_types.valve_category`）②温度分档→上阀盖约束（`low_temp`/`high_temp`）③各系列最小/最大口径（`pipe_size_min/max`，来自各 `structured_data.json` general_data.body.nominal_size）④系列不适用工况排除 |
| constraint | ~30 | ①温压限制（`body_pt_ratings`，`p1_max`+`temp_max`，action=require）②允许压差（`allowable_pressure_drops`，`dp_max`，action=require/exclude）③压力等级支持范围 ④泄漏等级（`leakage_class`，action=require）⑤空化/闪蒸（`flow_regime`→`require` GC210/GC320） |
| preference | ~20 | 液体空化→boost GC210/GC320；高压差气体降噪→boost GC320；大口径高含固→boost BT110；高温高压→boost BT310/GA510；小流量精调→boost GC210/GC120；`rangeability_required`→boost 满足者 |
| post_filter | ~10 | 开度窗口 penalty（方案 §4.2C 五类：调节液体 85/60-80/20、调节气体 90/60-80/20、开关 90/-/30、蝶阀 60~90、球阀 0~90）；`cv_min` 缺失→flag/warnings；`fd_mode`→set_field（flip `flags.fd_mode`）；补 `series_name`/阀型分类 flag |

### 脚本行为（`backend/seed_selection_rules.py`）
1. 读 `docs/selection_rules_v1.json`，逐条用 `SelectionRuleBase` 校验（含 category/action 枚举 + condition_expr 键白名单）
2. **dry-run 默认**：仅统计与校验、打印按 category 计数；`--commit` 才落库
3. upsert 幂等：**按 `rule_code` 原地 upsert**（命中则整体更新字段，未命中则插入）。
   - 决策原因（已实施）：`selection_rules.rule_code` 上有 UNIQUE 约束，无法同时保留「旧版 `is_active=False` 软删 + 新版插入」两条同 code 记录，故 P2 采用原地更新；
   - 规则版本化（软删历史 + 版本表）留待 **P5 规则管理 UI** 阶段，届时如需历史版本再调整表结构，P2 不做。
4. 使用 `SessionLocal`，插入后 `db.flush()`（会话 `autoflush=False`）
5. 禁全表 DELETE；仅按 `rule_code` 定向操作

**验证**：`python seed_selection_rules.py` 计数与方案预估一致（scope≈40/constraint≈30/preference≈20/post_filter≈10）；`--commit` 后 `SELECT category,COUNT(*) FROM selection_rules GROUP BY category` 吻合。

## 任务 2.2 匹配引擎骨架

**新建文件**：`backend/app/calc/selector.py`

### 数据结构
- `SelectionInput`（dataclass）：映射 `SelectionInput` Schema 字段（project_id/valve_id/media/flow_rate/p1/p2/t1/dp/pipe_size/leakage_class/valve_action/special_req/rangeability_required/cv_required…）
- `Candidate`（dataclass）：映射 `CandidateOut`（series_code/series_name/dn_label/trim_label/flow_char/rated_cv/cv_min/opening/rangeability/score/applied_rules/flags）

### 四阶段流水线 `ValveSelector.select(input) -> SelectionResultOut`
1. **scope**：取 `ValveType.is_active==True` 全量系列 → 逐系列应用 `category='scope'` 且 `target_series in ('*', series)` 的规则（exclude/require）
2. **constraint**：对存活系列查 `valve_cv_stk` 构造候选行（口径/阀芯/特性/压力等级），应用 constraint 规则 + `body_pt_ratings` 插值校核 + `allowable_pressure_drops` 校核
3. **preference**：对候选打分（`boost`/`penalty`，`action_payload` 给分值），累计 `score` + 记录 `applied_rules`
4. **post_filter**：`set_field`/`flag` 补字段；`penalty` 按开度窗口扣分；汇总 `warnings`
- 输出按 `score` 降序、附 `rank`
- 空输入/超范围输入不抛未捕获异常（捕获后进 `warnings`，返回空候选）

**验证**：构造 2-3 组样例输入，`select()` 返回候选且 shape 对齐 `SelectionResultOut`；非法输入返回空候选 + warnings。

## 任务 2.3 条件表达式求值器 `match_condition(expr, ctx)`

**位置**：`backend/app/calc/selector.py` 内独立函数（或同目录 `rule_eval.py`）

- 受限 JSON 字典比较：`{key: {op: value}}`，`op ∈ {_min,_max,_required,_eq,or...}`；支持方案 §2.1 白名单键
- **禁 `eval`/`exec`**；未知键 → 追加 warning 且视为**不匹配**
- `condition_op` 支持 `and`/`or`（多键组合）
- 支持布尔/枚举/数值/`or`（候选值集合）六类分支

**验证**：单测覆盖 `_min/_max/_required/枚举/布尔/or` 六类分支 + 未知键分支。

## 任务 2.4 Cv 反算与开度评估集成（复用既有引擎，不重写）

**位置**：`selector.py` 内 `_stage_evaluate_cv(...)`

### 复用点（同源，勿另造）
- Cv 计算：`app/calc/engine.py::calculate_case`（[engine.py](file:///d:/KELK%E5%8A%9E%E5%85%AC/%E4%BF%A1%E6%81%AF%E5%8C%96%E5%B7%A5%E4%BD%9C/207%20%E8%87%AA%E7%A0%94%E7%B3%BB%E7%BB%9F/KELKCalCv/backend/app/calc/engine.py)）
- 系数结构：`app/calc/cv_core.py::ValveCoeffs / FactorCurves / FactorCurve`
- 曲线配置：`app/api/valve_types.py::_get_cfg`（按 `series_code`+`pressure_rating` 取 `ValveSeriesCurveConfig`，含别名 `_resolve_curve_alias`）、`ValveFactorCurve`（按 `factor_type`+`eq_index` 取 FL/Kc/Fd 多项式）
- **行程曲线（stroke_mode 分派与 eqcv/系数）直接复用 `app/api/valve_types.py::_get_curves_by_selection_impl`（约 L1037–1600）**：它已按 `trim_type`/`trim_characteristics`/`plug_size`/`pressure_rating` 解析出 `effective_mode`、`stroke_info`(fstk/divisor/coeffs)、`eqcv` 曲线行、`fl/kc/fd` 曲线、`rated_cv`/`cv_min`/`stk_index`/`xT`。selector 传入候选参数调用它，**不重复实现 stroke_mode 判定**。
- 候选 Cv/行程：`ValveCvStk`（`rated_cv`/`cv_min`/`stroke_value`/`plug_mm`/`stk_index`）

### 构建 ValveCoeffs（镜像 `calculations.py::run_calculation` 的映射）
参照 [calculations.py](file:///d:/KELK%E5%8A%9E%E5%85%AC/%E4%BF%A1%E6%81%AF%E5%8C%96%E5%B7%A5%E4%BD%9C/207%20%E8%87%AA%E7%A0%94%E7%B3%BB%E7%BB%9F/KELKCalCv/backend/app/api/calculations.py#L241-L268)：
`rated_cv`←候选 `ValveCvStk.rated_cv`；`fl/xt/fd`←系列曲线配置（`fd_mode` 决定用表/公式）；`factor_curves`←`ValveFactorCurve`(FL/Kc/Fd) 组装为 `FactorCurves`；`stages` 取该系列默认（多级降噪）。

### 开度语义（已按用户确认修正）
- **`opening` = 曲线图中的 %Stk（行程百分比）**，不是 Cv 比%。
- 实现路径：
  1. 用 `calculate_case` 得到 `cv_required` 与 `rated_cv` → `phi = cv_required / rated_cv`（Cv 比）
  2. 按 `stroke_mode` 将 `phi` 反解为 `%Stk`：**移植前端 `frontend/src/views/Calculation.vue::evalEqcv`（L1153–1214）到后端**（新增 `selector.py::_cv_ratio_to_stk` 或独立 `stroke_curve.py`）
  3. `opening = %Stk × 100`
- 移植需覆盖全部 `stroke_mode` 分支（与前端逐一对应）：`linear` / `ln_eqn`（`1+ln(phi)/ln(fstk||50)`）/ `exp_formula`（`exp(A4·ln(Cv)+A3·Cv+A1/(Cv+A2)+A0)/divisor`，参数钳制 ±700）/ `poly_cv_div100`（`(A4·Cv⁴+…+A0)/100`）/ `poly_phi100_div100` / `poly_cv_div_angle`/`poly_div60`（`(A5·Cv⁵+…+A0)/divisor`）/ `eq_index`（φ 的霍纳多项式 A6..A0）。
- 曲线参数来源：`stroke_mode`、`eqcv` 系数行、`fstk`、`divisor` 均由 `_get_curves_by_selection_impl` 返回，逐字对齐前端（含 `divisor = opening_angle || divisor || 60` 的取值）。
- `rangeability = rated_cv / cv_min`；`cv_min` 为 `NULL` 时入 `warnings` 且 `rangeability=None`。
- 角行程系列（BT/BV）按 `cv_60deg/cv_90deg`（`open°`）与 `cv_metal_seat/cv_soft_seat`（`seat_type`）自动切换候选 Cv 行。
- 流态判定 `flow_regime` 由引擎返回，供 constraint/preference 阶段复用。
- 说明：因 `opening` 取 %Stk，与引擎 `CvResult.opening_pct`（Cv 比）在不同特性下不相等；P4 若要求「选型开度」与 `run_calculation` 的「开度 %」数值一致，需在 P4 同步统一 `CalcResult.cv_opening` 的口径（P4 待办，P2 不做）。

**验证**：对 GC120/GC210/BT210 已知工况手工对算，`opening`（%Stk）与曲线图标注点误差 < 1%；`_cv_ratio_to_stk` 覆盖全部分支。
