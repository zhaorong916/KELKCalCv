# 回归报告 R-20261120：1df041a → b74aea0 计算口径对比

- 报告编号：R-20261120
- 对比版本：`1df041a`（改前，线性开度/无缩径修正/无全压差参考 Cv） vs `b74aea0`（改后）
- 执行日期：2026-11-25
- 结论：**未变差**（开度 25 变好 / 52 持平 / 0 变差；Cv 0 变好 / 79 持平 / 0 变差）

## 1. 数据来源与脱敏

- 原始数据：`制造指示书详情导出2026-11-14_15_41_40.xlsx`（44 行阀门表，表 `制造书表头`）。
  仅本地读取，**未入库、未提交仓库**。
- 有效工况：80 条（有流量的槽位）；其中 3 条无样本开度、1 条无样本 Cv。
- 脱敏方式：位号按出现顺序替换为 `V001..V041`，工况号 `C001..C080`；保留型号、介质名、口径、流量/压力/温度/密度、额定 Cv 与样本 Cv/开度。
  脱敏结果：[regression_cases_sample.csv](../../scripts/regression/regression_cases_sample.csv)
- 逐条明细：[regression_detail_R-20261120.csv](../../scripts/regression/regression_detail_R-20261120.csv)

## 2. 计算口径

两个版本使用**完全相同**的输入与单位换算链，仅代码版本不同：

1. 原始值 + 原始单位 → `app.calc.units.convert_process_case`（与 `/run` 接口同一条路径）。
2. 单位归一：压力 `MPa(A)→MPaA`、温度 `Deg.C→℃`；流量 `NM3/H→Nm3_h`（标况 0℃）、`KG/H→kg_h`、`M3/H→m3_h`；密度 `KG/NM3→kg_Nm3`（按 P1/T1 修正到工况密度）、`KG/M3→kg_m3`。
3. 介质物性：空气 MW 28.97、氮气/污氮气 28.01/28.16、氧气 32.00（γ≈1.40）；液氮/液氧/富氧液空/水按液体，密度取样本值。
4. 阀门系数：蝶阀（型号以 `BT` 开头）FL=0.55、xT=0.35，其余 FL=0.9、xT=0.72，Fd=0.46；额定 Cv 取样本第 106 列。
5. 系列曲线：`valve_series_curve_config` + `valve_factor_curve`；无配置按产品前端 404 分支回落 `linear`。
6. 开度：旧版 = `Cv/Cv_rated×100`（线性）；新版 = `compute_opening` 按 Cv-行程曲线反算。

> 上一版临时脚本（中位偏差 +297%）因单位串与物性假设错误已废弃，本报告未复用其任何假设。

## 3. 判定阈值

- Cv：以样本 Cv 为基准，相对偏差变化 ≤0.5% 为「持平」，>0.5% 为「变差」，<-0.5% 为「变好」。
- 开度：以样本开度为基准，绝对误差变化 ≤0.5 个百分点为「持平」，否则按方向判「变好/变差」。

## 4. 总体结果

| 指标 | 变好 | 持平 | 变差 | 无样本 | 中位误差（旧→新） |
|---|---:|---:|---:|---:|---|
| Cv（相对偏差） | 0 | 79 | 0 | 1 | 0.92% → 1.22% |
| 开度（绝对误差） | 25 | 52 | 0 | 3 | 21.96pt → 19.31pt |

- 全部 80 条工况均完成计算，无异常中断。
- Cv 侧两版差异很小，最大变化 +0.39 个百分点（V001/V002 BT310D，0.92%→1.31%），未触发变差阈值。

## 5. 重点一：开度（线性 vs 特性曲线反算）

- 有系列曲线配置的 `GC120`、`BT210` 共 25 条判定为「变好」，典型：
  - V028/工况2（GC120）：样本 72.63%，旧 34.30%，新 72.65%（误差 38.33→0.02pt）
  - V039/工况3（BT210）：样本 91.35%，旧 67.18%，新 89.83%（24.17→1.52pt）
  - V041/工况3（BT210）：样本 81.39%，旧 55.44%，新 84.92%（25.95→3.53pt）
- 其余 52 条「持平」，主要因为 `BT310D / GV120D / GC210D / GC120D / GA510 / BV130` 在库中**无系列曲线配置**，新版按产品前端逻辑回落 `linear`，与旧版一致。
- **无「变差」条目**；曲线反算对已有曲线数据的系列明确改善，对无数据系列不劣化。

补充观察（未计入本次判定）：BT310D 与 BT310 同为三偏心结构，若补 `BT310D→BT310` 曲线别名，V001/V002 开度由线性 54.66% 变为 70.96%，与样本 71.07% 仅差 0.11pt。该别名需作为数据补齐项单独上线后再评估。

## 6. 重点二：缩径修正 Fp/FLp/xTp

- 新版按「阀座口径 < 管道内径−0.5mm」启用缩径修正。样本中 14 条触发，影响幅度如下：

| 阀门 | 口径/管内径 | Cv 相对变化 |
|---|---|---:|
| HV401A/HV401B（BT310D） | 250 / 264 | +0.379% |
| HV1711A/B、HV1811A/B（BT310D） | 125 / 127 | +0.013%～+0.018% |
| PV002（GV120D） | 80 / 83 | +0.085%～+0.225% |
| PV1801（GV120D） | 80 / 81 | +0.011% |
| PV008（GA510） | 100 / 102 | +0.014% |

- 结论：本批样本阀座与管内径接近，缩径修正量级 **≤0.38%**，不改变选型结论。

## 7. 重点三：全压差参考 Cv

- 液体工况 48 条输出 `Cv_full_dp`（不按阻塞截断、直接用工艺 ΔP 计算的参考 Cv）。
- 本批全部为**非阻塞（湍流）**，`Cv_full_dp` 与设计工况 Cv 完全一致（差异 >0.01 的条数 = 0）。
- 即：本样本中全压差参考 Cv 与设计 Cv 无差异，阻塞流口径对结果无影响。

## 8. 局限与数据缺口

- `BT310D / GV120D / GC210D / GC120D` 在 `ValveType` 与 `valve_series_curve_config` 中缺失，产品当前走线性兜底；其中 GV120D 样本开度实测更接近等百分比（R≈50），不宜直接映射 GV120 的 eq_index 曲线。
- `GA510 / BV130` 无系列曲线配置，MODIFIED_EQ% 特性暂以线性兜底，开度仍存在偏差（本次未劣化）。
- 液体蒸汽压缺省按水兜底，低温介质（液氮/液氧）空化判定不精确；两版一致，不影响版本对比结论。
- 噪音模型未标定，本报告不涉及。

## 9. 结论与建议

1. 第一步回归判定为 **未变差**，满足进入后续步骤条件。
2. 建议按计划打 `v1.0.0`。
3. 后续数据补齐（独立任务，不影响本次发版）：
   - 补 `BT310D` 曲线别名（已验证开度误差 0.11pt）；
   - 补 `GV120D` 等百分比（R=50）曲线配置；
   - 补 `GA510 / BV130` 系列曲线。
