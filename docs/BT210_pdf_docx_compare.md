## 一、核对方法

1. PDF 为唯一权威数据源。文字层页 p1/p2/p29/p30 用 pdfplumber 直读；**文字转曲页 p3–p28（text_len=0）** 用 pypdfium2 渲染 PNG 后逐图识别（转曲页 scale≈2.2）。
2. docx 34 表（table0–table33）全部由 OCR 重建，逐格与 PDF 比对：一致则采信；不一致以 PDF 为准并更正；docx 漏表按 PDF 补入。
3. 页码换算：**PDF 页 = 印刷页 + 2**（PDF p4 = 印刷页 2，PDF p27 = 印刷页 25，PDF p28 = 印刷页 26）。
4. 高密度压差表图像经整页高清渲染读取；OCR 数字粘连（如 `l 100`）必回图像复核。
