## 2. 标准规格（p4-5）

### 2.1 阀体 Body

| 项目 | 参数 |
|---|---|
| 公称通径 | 1"~20"（DN25~DN500） |
| 公称压力 | ANSI 150#/300#/600#；JB/T79.1-94 & HG/T20592-2009 PN1.6/4.0/6.3/10.0MPa |
| 连接方式 | 法兰型（RF、RTJ、MFM）；焊接型（2"以下 SW，3"以上 BW） |
| 设计标准 | ANSI B16.34、ANSI B16.47、API598 等 |
| 法兰距 | IEC60534、ISA S75.03-1985 |
| 表面涂层 | RAL7046 银灰色环氧树脂；不锈钢阀体不涂层 |

### 2.2 上阀盖 Bonnet（温度分档）

| 型式 | 温度范围 |
|---|---|
| 标准型 | -17 ~ +230℃ |
| 散热片型 | -45 ~ -5℃ 或 > +230℃ |
| 加长型 | -196 ~ -45℃ |

### 2.3 阀内件 Trim

- 形式：**流体压力平衡阀芯型**
- 流量特性：
  - **GC120**：等百分比 EQ%（IEC 标准）、线性 Linear、**改良等百分比 Md EQ%**、开关 On-off
  - **GC210**：线性 Linear、**改良等百分比 Md EQ%**、开关 On-off（**无标准 EQ%**）
- 阀座泄漏：金属阀座 ANSI Class IV（Class V 可选需咨询工厂）；软阀座 ANSI Class VI
- 填料/垫圈：按图4/图5 温压范围选用（R.TFE、碳纤维+PTFE、Grafoil 等）

### 2.4 执行机构 Actuator

| 项目 | 气动薄膜式 | 气缸式 |
|---|---|---|
| 用途 | 调节/开关 | 调节/开关 |
| 供气压力 | 300(弹簧80~200) / 340(80~200) / 340(120~300) / 400(140~280) kPa G | 400~500 kPa G |
| 接口 | Rc1/4（Ø650: Rc3/8） | Rc3/8~Rc3/4 |
| 作用方式 | 正作用 DA（气压增加阀闭）/ 反作用 RA（气压增加阀开） | 随定位器信号阀开/阀闭 |
| 环境温度 | -40 ~ +100℃ | -40 ~ +100℃ |

### 2.5 流向（p6-7 构造图）

| 系列 | 流向规则 |
|---|---|
| GC120 | 高进低出 Over plug flow（高温型同） |
| GC210 | **低进高出 Under plug flow（蒸汽及气体）/ 高进低出 Over plug flow（液体）** |

> GC210 按介质相态区分流向，这是其 Fd 公式中 KFo/KFb（Flow-to-Open / Flow-to-Close 方向额定 Cv）系数的物理来源。

### 4.2 GC210（多孔套筒 410/HT 或 316）

结构与 GC120 类似，差异：套筒为多孔式（Multi-hole Cage），不锈钢组合的阀芯带 Hcr 镀硬铬处理。
处理代号：HT=热处理，PH=析出硬化，Hcr=镀硬铬，SS=部分堆焊司太莱，SF=全堆焊司太莱，R.TFE=强化四氟。

### 4.3 选型规则（样本注释）

- 空化气蚀工况 → 选 GC210/GC320（多孔降压）
- 闪蒸工况 → 选缩腔型 + 阀芯阀座全堆焊司太莱（SF）
- 禁铜工况 → 套筒 630/PH 改用 410/HT
- Class V 泄漏 → 咨询工厂

## 5. 最大允许压差（p13-14 表4，单位 MPa）

按 **执行机构型式/尺寸 × 气源压力 × 弹簧范围 × 阀座（金属/软） × 阀芯尺寸 × 平衡密封环材质** 查表：

| 表号 | 执行机构 | 填料/平衡密封环 | 阀芯范围 | 压差上限 |
|---|---|---|---|---|
| 4-1 | 薄膜 PD3000LA（270/350/450/650） | R.TFE | 1"~12" | 金属 9.89，软密封 3.00 |
| 4-2 | 薄膜 PD3000LA（350/450/650） | Grafoil | 1"~12" | 金属 8.33 |
| 4-3 | 气缸双动作 PC3200LA（200/300/450/600） | R.TFE | 4"~20" | 金属 9.89，软 3.00 |
| 4-4 | 气缸双动作 PC3200LA（300/450/600） | Grafoil | 4"~20" | 金属 8.33 |

规律：金属密封上限 9.89 MPa（R.TFE 环）/ 8.33 MPa（Grafoil 环），软密封一律 3.00 MPa；大阀芯（不平衡力大）或小执行机构时按表递减（如 PD3000LA-450 + 8" 阀芯 = 5.00~6.65 MPa）。完整数据见 JSON `allowable_pressure_drops`。

### 8.2 数据结构

```text
dimensions["<actuator_family>_<action>"]
├── actuator_family        PD3000LA / PD304LLA / PD306SLA / PD306LLA / PC3200LA
├── action                 D（正作用）/ R（反作用）/ W（双作用）
└── dn_rows[]
    ├── dn_inch / dn_mm
    ├── face_to_face{}      法兰距（7个键）：L150_RF, L300_RF, L300_SWBW, L300_RTJ,
    │                        L600_RF, L600_SWBW, L600_RTJ（150#仅RF；300#/600#各3种连接形式）
    ├── H2                  阀体高度
    ├── h1_std / h1_fin     上阀盖高度（标准型 / 散热片型）
    └── actuators[]         该口径可选执行机构（同一口径可能有多个型号）
        ├── model           执行机构型号（PD3021LA / PC3220LA 等）
        ├── H1_std / H1_fin 执行机构+上阀盖总高（标准型 / 散热片型）
        ├── A / B           执行机构外径相关（PD3000LA 有值，其余多数为空）
        ├── L1              手轮/侧装手柄中心距（PC3200LA 有值）
        ├── L2              行程调节范围（PD3000LA/PD304LLA 有值，格式 "min~max"）
        ├── W               手轮/执行机构宽度
        ├── H_repair        维修空间高度（PC3200LA 为空）
        ├── H3_std / H4_std / H3_fin / H4_fin   带手轮时高度（PD306SLA/LLA、PC3200LA）
        └── size / D / R    PC3200LA 气缸尺寸/缸径/接口螺纹（仅 PC3200LA）
```

### 8.3 查询键（前端自动获取外形尺寸）

程序按以下维度组合查询：

```
执行机构族(actuator_family) + 作用方式(action) + 口径(dn_mm) + 执行机构型号(model) + 上阀盖型式(std/fin)
```

- **上阀盖型式**：取 `h1_std/H1_std/H3_std/H4_std`（标准型）或 `h1_fin/H1_fin/H3_fin/H4_fin`（散热片型）。
- **法兰距**：按阀体压力等级（150#/300#/600#）和连接形式（RF/SWBW/RTJ）从 `face_to_face` 取对应键。
- **口径匹配**：`dn_mm` 字符串精确匹配（"25","40",...,"500"）。
- **执行机构型号匹配**：同一口径下 `actuators[]` 可能有多个型号（如 DN150 配 PC3220LA 或 PC3230LA），按用户选型的 `model` 过滤。

### 8.4 数值规则说明

1. **L2 行程范围**：已统一归一化为 `min~max`（PDF 中 D 作用部分行写为 `max~min`，提取时已排序）。
2. **空值**：不适用的尺寸字段存为 `null`（如 PD304LLA 的 A/B/L1、PC3200LA 的 H_repair）。
3. **PD3000LA**：DN25~DN100，每个口径可选 1~4 个执行器型号（PD3021LA/3027LA/3035LA/304SLA）；D 与 R 仅 H1/L2 不同，法兰距与 H2/h1 相同。
4. **PD306SLA/LLA、PC3200LA**：D 与 R 的尺寸数值相同（作用方式不影响外形尺寸）。
5. **PC3200LA**：DN150~DN400 每口径有 2 个气缸尺寸选项（如 PC3220LA/PC3230LA），DN450 仅 PC3260LA；含气缸尺寸 `size`、缸径 `D`、接口 `R`、中心距 `L1`。

## 10. 程序开发建议

1. **直接可用**：`GC120_210_structured_data.json` 中 `rated_cv_stroke` 已按 (series, dn, plug, 特性) 展开，含 `is_full_port` 标记，可整体导入或做初始化种子数据比对。
2. **GC210 最小可控 Cv**：PDF 表3-2 是唯一数据源，若可调比/最小开度校核功能需要，建议在 `valve_cv_stk` 增加 `cv_min` 列后按 JSON `modified_eq_pct.cv_min` / `linear.cv_min` 导入。
3. **温压校核**：`body_pressure_temperature_ratings.ansi`（279 条）支持按温度线性插值，温度档 -196~38/-45~38/-5~38/50/100/150/200/250/300/350/375/400/425/450/475/500/525/538℃。
4. **压差校核**：查表键 = (执行机构型号+尺寸, 气源压力, 密封形式, 阀芯 inch)；注意 GC210 流向（蒸汽/气体 Under plug、液体 Over plug）影响 Fd 与压差校核口径。
5. **样本未含**：FL/Fd/xT 逐点开度系数、噪音计算数据、GC120H/HH、GC210H/HH 等派生型号（DB 中 GC120D/H/HH、GC210D/H/HH 共 216 行来自其他资料，本样本不覆盖）。
6. **外形尺寸自动获取**：`docs/GC120_210_dimensions.json` 已结构化为 9 个执行机构族×作用方式的二维表，前端可按 `actuator_family + action + dn_mm + model + 上阀盖型式(std/fin)` 查询并返回法兰距、总高 H1、手轮相关 H3/H4、中心距 L1/L2、维修空间 H 等完整外形参数，直接用于外形图渲染或安装空间校核。
