## 1. 模块定位与职责

「阀门型号」模块对应前端路由 `/valve-types`（[ValveTypes.vue](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/frontend/src/views/ValveTypes.vue)），后端 API 入口为 [valve_types.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/api/valve_types.py)。

### 1.1 核心职责

| 职责 | 说明 |
|------|------|
| 产品系列字典 | 提供 KELK 全部阀门系列（GC120/BT210/...）的型号、类别、说明 |
| Trim/Cv 额定容量表 | 展示 Excel "Table 1 Rated Capacities" 数据（压力等级 × 口径 × 阀芯 → 额定 Cv） |
| 系数曲线选择 | 根据压力等级、阀芯尺寸、Trim 类型，确定 FL / Kc / Fd / Stroke 曲线索引 |
| 系数曲线展示 | 渲染 FL/Kc/Fd 随 φ(=Cv/Cvrated) 变化的曲线与特征值表 |
| 系数输出 | 为计算引擎提供 FL、xT、Fd、额定 Cv、开度曲线等输入参数 |

### 1.2 与计算引擎的关系

阀门型号模块**不执行 Cv 计算**，而是为计算引擎（[cv_liquid.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_liquid.py) / [cv_gas.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_gas.py)）提供阀门系数输入。计算流程见 [计算过程文档.md](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/docs/计算过程文档.md)。

## 3. 数据库表结构与数据来源映射

### 3.1 核心表 ER 关系

```
valve_types (产品系列字典)
    │
    ├── valve_series_curve_config (系列曲线配置：FL/Kc/Fd/Stroke 索引)
    │       └── 唯一约束 (series_code, pressure_rating)
    │
    ├── valve_trim_sizes (Trim/Cv 额定容量表 = Excel Table 1 + Table 2)
    │       └── 索引 (series_code, asme_class, dn_mm)
    │
    ├── valve_plug_index_map (阀芯→%Stk Index 映射 = Excel Table 2)
    │       └── 唯一约束 (series_code, asme_class, plug_mm)
    │
    ├── valve_filter_config (筛选器配置，前端动态渲染)
    │
    └── valve_factor_curves (系数曲线多项式数据 = Eq%/FL/Kc/Fd Data Sheet)
            └── 唯一约束 (factor_type, eq_index)
```

### 3.2 表与 Excel Sheet 对照

| 数据库表 | Excel 来源 | 关键列映射 |
|---------|-----------|-----------|
| `valve_types` | 各 Sheet Row1 名称 + 人工整理 | series_code, series_name, valve_category |
| `valve_trim_sizes` | 各 Sheet **Table 1** (R7+) | asme_class→B列, dn_mm→C列, plug_mm→E列, stroke_mm→F列, cv_eq→G列 |
| `valve_plug_index_map` | 各 Sheet **Table 2** (R78+) | asme_class→B列, plug_mm→C列, stk_index→D列 |
| `valve_factor_curves` (eqcv) | **Eq% Data** Sheet | eq_index→A列, a0~a6→H~B列 |
| `valve_factor_curves` (fl) | **FL Data** Sheet | eq_index→A列, value_min→B, value_max→C, p0~p4→H~D列 |
| `valve_factor_curves` (kc) | **Kc Data** Sheet | 同 FL Data 结构 |
| `valve_factor_curves` (fd) | **Fd Data** Sheet | 同 FL Data 结构 |
| `valve_series_curve_config` | 各 Sheet **Choices for Graphs** 的索引写死值 | fl_eq_index, kc_eq_index, stroke_mode, stroke_fstk |
| `valve_filter_config` | 各 Sheet **Trim Options** (R3-R6) | filter_key, display_label, option_source |

### 3.3 ValveFactorCurve 多项式系数存储

```
Eq% Data Sheet 表头 (R5):  A6  A5  A4  A3  A2  A1  A0
数据库列:                   a6  a5  a4  a3  a2  a1  a0

FL Data Sheet 表头 (R5):   P4  P3  P2  P1  P0
数据库列:                   p4  p3  p2  p1  p0
```

> **注意**：Excel 中 Eq% 系数按 **A6→A0** 从左到右排列（高次项在前），数据库 `a0`=常数项，`a6`=六次项，与多项式标准写法 `y = a0 + a1·x + ... + a6·x⁶` 一致。前端用 Horner 法 `((((a6·x+a5)·x+a4)·x+...+a1)·x+a0` 计算。

## 4. API 数据获取流程

### 4.1 接口清单

| 接口 | 方法 | 用途 |
|------|------|------|
| `/valve-types` | GET | 获取全部启用系列列表 |
| `/valve-types/{code}` | GET | 单个系列详情 |
| `/valve-types/{code}/curve-options` | GET | 获取该系列所有筛选选项 + Table1/Table2 + 默认配置 |
| `/valve-types/{code}/curves-by-selection` | GET | 按选择参数返回实际曲线 + xT + rated_cv |
| `/valve-types/{code}/factor-curves` | GET | 默认系数曲线（简化版） |
| `/valve-types/{code}/trim-sizes` | GET | 完整 Trim/Cv 表 |

### 4.2 curve-options 数据获取流程

```
前端调用 /valve-types/GC120/curve-options
  │
  ├─ 1. 查 valve_types → 确认系列存在
  ├─ 2. _get_cfg(series, "", db) → 查 valve_series_curve_config (默认配置)
  │
  ├─ 3. 收集压力等级:
  │     DISTINCT valve_plug_index_map.asme_class (≠'all')
  │     ∪ DISTINCT valve_trim_sizes.asme_class
  │
  ├─ 4. Trim Characteristics: ["EQ%", "Linear"] (或 valve_types.trim_option_types)
  │
  ├─ 5. Trim/Seat Type: DISTINCT valve_trim_sizes.trim_type
  │
  ├─ 6. 级联数据 (GV120 等):
  │     按 trim_type → pressure_ratings → dn_ranges → plug_table
  │     输出 cascade + table1 + table2
  │
  ├─ 7. 传统阀芯尺寸:
  │     按 pressure_rating 查 valve_plug_index_map.plug_mm
  │     兜底查 valve_trim_sizes (BT/BC/BE 用 dn_mm)
  │     输出 plug_sizes_by_pressure
  │
  ├─ 8. 筛选器配置: 查 valve_filter_config (按 filter_order)
  │     source=data → 从 trim_sizes/plug_index_map 取列
  │     source=hardcoded → 解析 JSON 选项
  │     source=cascade → 按 dependent_on 分组
  │
  └─ 9. 组装返回: filters + filter_configs + cascade + table1/table2 + default_selection + cfg
```

### 4.3 curves-by-selection 数据获取流程（核心）

这是将用户选择转化为**实际曲线数据**的接口，完全复现 Excel "Choices for Graphs" 的查找逻辑：

```
输入: series_code, pressure_rating, plug_size, trim_type, trim_seat_type
  │
  ├─ 1. cfg = _get_cfg(series, pressure_rating, db)
  │     优先精确匹配 (series + pressure_rating)
  │     兜底匹配 (series + pressure_rating IS NULL)
  │     → 得到 fl_eq_index, kc_eq_index, fd_mode, stroke_mode 等
  │
  ├─ 2. 查 FL/Kc/Fd 曲线:
  │     fl_curve = valve_factor_curves WHERE factor_type='fl' AND eq_index=cfg.fl_eq_index
  │     kc_curve = valve_factor_curves WHERE factor_type='kc' AND eq_index=cfg.kc_eq_index
  │     fd_curve = (fd_mode='table' 时才查)
  │
  ├─ 3. rated_cv 查找 (4 级兜底策略):
  │     策略1: pressure + 尺寸 + trim_type 精确匹配 valve_trim_sizes
  │     策略2: GV120 按 trim_type + plug_mm 匹配
  │     策略3: 仅尺寸匹配 (忽略 pressure)
  │     策略4: plug_mm 或 dn_mm 任一匹配
  │     → 按系列选字段: 蝶阀用 cv_60deg/cv_90deg, 球阀用 cv_metal/soft_seat, 调节阀用 cv_eq
  │
  ├─ 4. Stroke Curve 模式决策:
  │     默认 cfg.stroke_mode
  │     GC120/GC210 且 pressure='< 600#' → 强制 ln_eqn (Fstk=50)
  │     GV120: Large-Cv → poly_cv_div100; 其他 → ln_eqn
  │
  ├─ 5. eqcv 曲线查找 (eq_index/poly_* 模式):
  │     查 valve_plug_index_map(series, rating, plug) → stk_index
  │     再查 valve_factor_curves WHERE factor_type='eqcv' AND eq_index=stk_index
  │
  ├─ 6. xT 计算:
  │     FL(φ=1) = P0+P1+P2+P3+P4 (多项式求和，常数曲线取 value_max)
  │     xT = 0.84 × FL(φ=1)²
  │
  └─ 7. 返回: stroke_info + eqcv + fl + kc + fd + xt_calculated + rated_cv
```

## 5. 系数曲线计算逻辑与方法

### 5.1 统一变量定义

所有曲线的自变量为 **φ = Cv / Cv_rated**（相对流量系数），取值范围 [0, 1]。

### 5.2 行程曲线 %Stk = f(φ)

| stroke_mode | 公式 | 适用系列 | Excel 出处 |
|------------|------|---------|-----------|
| `eq_index` | `%Stk = A0 + A1·φ + A2·φ² + ... + A6·φ⁶` | GC120(900#/1500#/2500#), GC210 | GC120 R111 `INDEX(Table2)` + Eq% Data |
| `ln_eqn` | `%Stk = 1 + ln(φ) / ln(Fstk)` | GC120(<600#), GV410, GV120(非Large) | GC120 R113 `Ln(Cv/Cvrated)/Ln(Fstk)+1` |
| `linear` | `%Stk = φ` | GV110 | 线性特性 |
| `exp_formula` | `%Stk = Exp(A4·ln(Cv)+A3·Cv+A1/(Cv+A2)+A0) / 60` | BT110, BT120 | 蝶阀指数公式 |
| `poly_div60` | `%Stk = (A5·φ⁵+...+A0) / 60` | BT210 | 蝶阀多项式÷60 |
| `poly_cv_div100` | `%Stk = (A4·Cv⁴+...+A0) / 100` | GV120 Large-Cv | GV120 大流量 |
| `poly_phi100_div100` | `%Stk = (A4·(φ·100)⁴+...+A0) / 100` | BE120 | 球阀多项式 |

### 5.3 FL / Kc / Fd 系数曲线

所有系数曲线统一为 **4 次多项式**（常数曲线时系数全 0，取 value_max）：

```
Factor(φ) = P0 + P1·φ + P2·φ² + P3·φ³ + P4·φ⁴
```

钳制到 [value_min, value_max]。

**Excel 对照**：FL Data / Kc Data / Fd Data Sheet 每行：
- A列 = Eq% Index
- B列 = Minimum Value
- C列 = Maximum Value
- D~H列 = P4, P3, P2, P1, P0

**示例（FL Index=1）**：
- Excel: P0=0.9863, P1=-0.2174, P2=0.208, P3=-0.0816, P4=0
- φ=1 时: FL = 0.9863 - 0.2174 + 0.208 - 0.0816 + 0 = **0.8953**（≈0.9，与 value_min 一致）

### 5.4 常数曲线判定

当 P0~P4 全为 0 且 value_min == value_max 时，曲线为常数：
```
Factor(φ) = value_min  (对所有 φ)
```

如 GC120 的 FL Index=2: value_min=value_max=0.94，FL 恒为 0.94。

### 5.5 xT 推导

```
xT = 0.84 × FL(φ=1.0)²
```

**Excel 对照**：GC120 R119 `xT = 0.84*FL²`（其中 FL 取 φ=1 时的值）。

## 6. 开度（%Stk）计算 — 与 Excel 对照

### 6.1 开度计算.xlsx 原始公式

[开度计算.xlsx](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/参考文件/开度计算.xlsx) Sheet1 R16-R17 注释明确给出：

```
EQ%:     开度 = ( LOG(Range, Cvc/Cvrated) + 1 ) × 100%
LINEAR:  开度 = ( Cvc/Cvrated - 1/Range ) / ( 1 - 1/Range ) × 100%
```

其中：
- `Range` = 可调比 = Cv_max / Cv_min（典型值 50 ）
- `Cvc` = 当前工况所需 Cv
- `Cvrated` = 阀门额定 Cv

### 6.2 与系统 ln_eqn 模式的对照

系统 `ln_eqn` 模式公式：`%Stk = 1 + ln(φ) / ln(Fstk)`

将 Excel EQ% 公式变形：
```
开度 = LOG(Range, Cvc/Cvrated) + 1
     = ln(Cvc/Cvrated) / ln(Range) + 1
     = 1 + ln(φ) / ln(Range)
```

令 `Fstk = Range`，则：
```
%Stk = 1 + ln(φ) / ln(Fstk)    ← 与系统 ln_eqn 完全一致
```

**结论**：系统 `ln_eqn` 模式的 `Fstk` 参数 = Excel 的 `Range`（可调比）。GC120 的 Fstk=50 即表示可调比 50:1。

### 6.3 开度反解（前端实现）

前端需要从 %Stk 反求 φ（绘制 Cv vs Travel 曲线），由于多项式无解析反函数，使用**二分法**求解 `f(φ) = targetStk`：

```
给定 stk ∈ [0, 1]:
  二分搜索 φ ∈ [0, 1]，使 evalEqcv(φ) ≈ stk
  精度: 1e-6
```

Excel 中此步通过图表 X-Y 轴互换实现，系统用数值方法等价复现。

### 6.4 Linear 特性对照

Excel LINEAR 公式：`开度 = (φ - 1/Range) / (1 - 1/Range)`

当 Range 很大（如 50）时，1/Range ≈ 0，公式退化为 `开度 ≈ φ`，与系统 `linear` 模式 `%Stk = φ` 一致。

> **差异**：系统 Linear 模式未引入 Range 参数，直接 `%Stk = φ`。当 Range 较小时存在偏差，需评估是否需要修正。

## 7. Cv 计算公式 — 与 Excel 对照

### 7.1 液体 Cv

| 项目 | Excel (Cv_2.1.xlsm Liquid) | 系统 (cv_liquid.py) |
|------|---------------------------|---------------------|
| 标准 | IEC 60534-2-1 / ISA-75.01 | IEC 60534-2-1 / GB/T 17213.2 |
| 单位 | barA, m³/h, kg/m³ | kPa(abs), m³/h, kg/m³ |
| FF 公式 | `IF(Pc≤Pv, 0.68, 0.96-0.28·√(Pv/Pc))` (R95) | 同 (L66-72) |
| ΔPch | `(Fl)²·(P1 - Ff·Pv)` | 同 (L73) |
| 阻塞判定 | `ΔP < ΔPch ? 非阻塞 : 阻塞` | 同 (L78) |
| Cv 公式 | `Qf / (N1·Fp·Fr) · √(ρ/ΔP)` | `W / (K_LIQ·Fp·√(ΔP·ρ))` (L88) |
| 常数 N1 | Excel 内部单位换算系数 | K_LIQ = 2.7351 (kPa 体系) |
| 雷诺数 Fr | `IF(Rev<10, 0.026/Fl·√(n·Rev), MIN(1+(0.33·√Fl/n^0.25)·log10(Rev/10000), ...))` | 同 (cv_core.py L208-255) |
| n 系数 | `IF(Cd≥0.016, 0.00214/Cd², 1+127·Cd^(2/3))` | 同 (cv_core.py L236-239) |

> **单位差异**：Excel 使用 barA，系统使用 kPa。常数 K_LIQ=2.7351 是 N1 在 kPa 体系下的换算值，已通过算例验证（水 Q=120m³/h, ΔP=460kPa → Cv=64.7）。

### 7.2 气体 Cv

| 项目 | Excel (Cv_2.1.xlsm Gas R98-R104) | 系统 (cv_gas.py) |
|------|--------------------------------|-----------------|
| Fγ (Fk) | `k/1.4` (R98) | `γ/1.4` (L55) |
| x | `MIN(Fk·Xtp, (P1-P2)/P1)` (R99) | `MIN(x, Fγ·xT)` (L64) |
| Y | `1 - x/(3·Fk·Xtp)` (R100) | `1 - x_eff/(3·xT_eff)` (L65) |
| Cv | `Wg/(31.6·Fp·Y·√(x·P1·ρ1))` (R104) | `W/(K_GAS·Fp·Y·√(x_eff·P1·ρ1))` (L81) |
| 常数 | 31.6 (barA 体系) | K_GAS = 2.733 (kPa 体系) |
| 阻塞 | `x ≥ Fk·Xtp` → Y=0.667 | 同 (L62-66) |

> **单位差异**：Excel 用 31.6（barA 体系 N6 系数），系统用 K_GAS=2.733（kPa 体系）。换算关系：31.6 × √(100) / 1000 ≈ 2.73（bar→kPa，kg/h→kg/s 等换算）。

## 8. xT 与阀门系数推导

### 8.1 xT 计算链

```
FL(φ=1)  ←  valve_factor_curves (fl, eq_index=cfg.fl_eq_index)
   │
   ├─ 若为常数曲线: FL = value_max
   └─ 若为多项式:  FL = P0+P1+P2+P3+P4
   │
   ▼
xT = 0.84 × FL²
```

**Excel 对照**：GC120 Sheet R119 `xT = 0.84*FL²`，其中 FL 来自 R115 的 VLOOKUP 结果在 φ=1 时的值。

### 8.2 各系列 FL/Kc/Fd 索引配置

| GC210 | 2 | 2 | **KFd查表**（见下） | 0.94 (常数) | 0.85 (常数) |
| BC110 | 4 | 4 | 4 | 0.604~0.92 | 0.30~0.655 |
| BE120 | 5 | 5 | 5 | 0.85~0.953 | 0.60~0.76 |

### 8.3 Fd（阀门型式修正系数）

Fd 有三种获取模式：

| 模式 | fd_mode | 说明 | 适用系列 |
|------|---------|------|---------|
| 查表曲线 | `table` | Fd 为关于 φ 的多项式曲线，从 Fd Data 表按 idx 查找 | GC120, GV(FTC), BC, BE, BT |
| KFd 查表 | `kfd` | Fd 为根据 plug_size 查到的固定常数 | GC210 |
| 动态公式 | `eqn` | Fd 依赖工况参数（CvReq, ΔP, FL），在 Cv 计算时动态计算 | GV(FTO) |

**Excel 对照**：
- GC120 R117 `Fd = IF(Trim="Linear", 1, 2)` — 依赖 Trim 类型
- GC210 R110 `Fd = Eqn`，实际为 `VLOOKUP(PlugSize, C82:F98, KFd列)` — 依赖 Plug Size
- GV 系列 `Fd = IF(Dxx="FTO", "Eqn", 3)` — FTO 时用公式，FTC 时查表 idx=3
- BT 系列 `Fd = IF(angle="60Deg", 6, 7)` — 依赖阀板角度

**GV FTO 动态公式**：
```
Fd = 1.13 × √(17 × CvReq × FL) / (2 × ΔP - (17 × CvReq × FL) / ΔP)
```
其中 CvReq 为所需 Cv，ΔP 为压力降，FL 为当前开度下的压力恢复系数。
