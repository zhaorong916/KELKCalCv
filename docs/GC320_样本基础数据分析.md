## 4. 数据结构说明

### 4.1 额定Cv及行程（rated_cv_stroke）- 最关键表

**数据源**：PDF page 10 (printed page 8) 渲染图像提取

**查询键**：`(valve_inch, plug_inch, stroke_mm)` 或 `(valve_mm, plug_mm, stroke_mm)`

**列定义**：
| 字段 | 说明 | 示例 |
|------|------|------|
| valve_inch | 公称通径(英寸) | "1-1/2" |
| valve_mm | 公称通径(mm) | "40" |
| plug_inch | 阀芯尺寸(英寸) | "1" |
| plug_mm | 阀芯尺寸(mm) | "25" |
| stroke_mm | 行程(mm) | "20" |
| min_cv | 最小可控Cv | "0.48" |
| cv_1stg | 1级降压额定Cv | "16" |
| cv_2stg | 2级降压额定Cv | "10.8" |
| cv_4stg | 4级降压额定Cv | "8.3" |
| cv_6stg | 6级降压额定Cv | "6.7" |
| cv_8stg | 8级降压额定Cv | "4.6" |

**特殊说明**：
- 1" 阀门配 1/2" 阀芯仅有8级降压配置（cv_1stg~cv_6stg 为 "—"）
- 20" 阀门配 18" 阀芯在 stroke=200 时无1级降压（cv_1stg="—"）
- 共24行数据，覆盖 1"~20" (DN25~DN500) 全部口径
- 级数越多，相同口径下额定Cv越小（多级降噪）

### 4.2 额定Cv(口径×压力等级)（rated_cv_by_size）

**数据源**：docx Table 14

**查询键**：`valve_inch` 或 `valve_mm`

**列定义**：inch, mm, ANSI 150#(PN1.6MPa), ANSI 300#(PN4.0MPa), ANSI 600#(PN6.3/PN10MPa)

**说明**：此表为按口径和压力等级的额定Cv值，可能是1级降压的最大Cv。与 rated_cv_stroke 表的 cv_1stg 字段可能有对应关系。

### 4.3 允许压差（allowable_pressure_drops）

**数据源**：docx Tables 11-13

**三张子表**：
| 子表 | 执行机构 | 填料 | 平衡密封环 | 阀芯尺寸范围 |
|------|---------|------|-----------|-------------|
| table_4_1_diaphragm_ptfe | PD3000LA 薄膜式 | R.TFE+碳纤维 | R.TFE/316 | 1/2"~16" |
| table_4_2_diaphragm_grafoil | PD3000LA 薄膜式 | 柔性石墨 | 柔性石墨 | 1/2"~16" |
| table_4_3_cylinder_ptfe | PC3200LA 气缸式 | R.TFE+碳纤维 | R.TFE/316 | 4"~16" |

**查询键**：`(actuator_size, air_supply, spring_range, seat_type, plug_size)`

**值含义**：最大允许压差(MPa)。"—"表示该组合不可用。

### 4.4 材质组合（material_combinations）

**数据源**：docx Tables 6-7

**碳钢/合金钢表(Table 6)**：4种阀内件组合
- 组合1: 阀芯410/HT, 阀座316/R.TFE, 套筒410/HT, 密封环R.TFE, 泄漏Class VI
- 组合2: 阀芯410/HT, 阀座410/HT, 套筒410/HT, 密封环R.TFE, 泄漏Class IV
- 组合3: 阀芯410/HT, 阀座410/HT, 套筒410/HT, 密封环柔性石墨, 泄漏Class IV
- 组合4: 阀芯316/SF, 阀座316/SF, 套筒316, 密封环柔性石墨, 泄漏Class IV

**不锈钢表(Table 7)**：4种阀内件组合
- 组合1: 阀芯316/Hcr, 阀座316/R.TFE, 套筒316, 密封环R.TFE, 泄漏Class VI
- 组合2: 阀芯316/Hcr+SS, 阀座316/SS, 套筒316, 密封环R.TFE, 泄漏Class IV
- 组合3: 阀芯316/Hcr+SS, 阀座316/SS, 套筒316, 密封环柔性石墨, 泄漏Class IV
- 组合4: 阀芯316/SF, 阀座316/SS, 套筒316, 密封环柔性石墨, 泄漏Class IV

### 4.5 温压额定值（body_pt_ratings）

- 温度范围: -196℃ ~ 538℃

## 5. 与 GC120&210 的差异

| 对比项 | GC120&210 | GC320 |
|--------|-----------|-------|
| 阀芯形式 | 套筒导向型 Cage Guided | 多级降压式套筒 Multi-stage Cage |
| Cv级数 | 单级（EQ%/Linear） | 1/2/4/6/8级降压 |
| Cv表 | 按口径×阀芯尺寸×流量特性 | 按口径×阀芯尺寸×行程×级数 |
| 压差表 | 按执行机构×口径 | 按执行机构×阀芯尺寸×密封形式 |
| 执行机构 | PD3000LA(薄膜) + PC3200LA(气缸) | 相同 |
| 材质组合 | 碳钢/合金钢 + 不锈钢 | 相同结构，4组合×2大类 |
| 温压表 | ANSI Class + PN | 相同 |
| 尺寸表 | 9张（1"~20"） | 9张（1"~18"，含侧装手轮变体） |

## 6. 注意事项

1. **Table 3(Cv&Stroke) 数据来自图像识别**：由于PDF该页为文字转曲，docx中为空表。数据通过 pypdfium2 渲染 PNG 后从图像提取，建议在关键应用前与原PDF逐条核对。
2. **尺寸表有重复**：Tables 22/23 和 24/25 数据相同，可能是PDF排版重复或续页。
3. **Table 14(rated_cv_by_size) 与 rated_cv_stroke.cv_1stg 的关系**：Table 14 按 ANSI 压力等级给出Cv，而 rated_cv_stroke 的 cv_1stg 是1级降压值，两者可能需要交叉验证。
4. **允许压差值多为 9.89 和 8.33**：Tables 11-13 中大量单元格值为 9.89 或 8.33，这些可能是系统额定上限值而非实际压差计算结果，需结合实际工况验证。
5. **PN温压表(Table 28)为双联表**：左半为ZG230-450碳钢，右半为ZG0Cr18Ni9不锈钢，结构化时已拆分为left/right两部分。
