1b. 两份 Excel Cv 计算一致性结论

结论：Cv 计算逻辑高度一致，差异仅在标准版本引用与功能覆盖范围

Cv_2.1.xlsm 与 Aerodynamic Noise 3.6.xlsm 共享同一套 IEC 60534-2-1 流量方程、同一张 ValveData/FluidData/PipeData 数据表、同一套 VBA 物性函数。对于气体 Cv 计算，两份 Excel 的方法和取数逻辑完全一致，差异对照只需对标一份即可代表两份。

1b.4 Cv 计算方向的差异

维度Cv_2.1.xlsmNoise 3.6.xlsm
计算方向 正向：由流量/压差 → 计算所需 Cv（选型用） 反向：已知 Cv → 反算流量/流态参数（噪音预测用）
Cv 的角色 Cv 是输出结果 Cv 是输入参数（用户已选定阀门后预测噪音）
流态判定用途 判定阻塞/非阻塞，选择 Cv 公式分支 判定 5 级 Regime (I~V)，选择声效率 η 和峰值频率 fp 公式

小结：两份 Excel 在 Cv 计算的核心公式、数据表、物性函数上完全一致。Cv_2.1 是专门的 Cv 选型工具（含液体/气体/两相/湿蒸汽），Noise 3.6 在同一 Cv 计算框架上扩展了噪音预测功能（5 级 Regime + 倍频程频谱）。标准版本差异（2002 vs 2007）仅为重新确认，公式无实质变化。后续与项目代码对标时，气体 Cv 部分取任一份 Excel 均可代表。

3. 液体 Cv 计算

3.1 基本公式对照

一致 非阻塞流 Cv

来源公式
ExcelC = Qf / (Fp·Fr) × √(ρ1 / (1000·ΔP))
项目cv = (mass_flow / (K_LIQ · fp · √(dp_eff · density))) / Fr，Fr 按 IEC Annex G 计算（层流系数 n + Rev 三分支公式）

说明：Fr 于 2026-09-04 补齐，与 Excel 逻辑一致（Cd ≥ 0.016 → n=0.00214/Cd²；否则 n=1+127·Cd^(2/3)）。高粘度甘油 Rev=39 时 Cv 增大 ×2.68（Fr=0.373）；Rev≥10000 Fr=1.0。

一致 阻塞流 Cv

来源公式
ExcelC = Qf / (Flp·Fr) × √(ρ1 / (1000·(P1 - Ff·Pv)))
项目cv = (mass_flow / (K_LIQ · fp · √(dp_choked · density))) / Fr, dp_choked = fl²·(p1 - ff·pv)

说明：阻塞公式与 Fr 修正均已对齐 (2026-09-04)。

3.2 差异明细

差异项Excel项目影响
Ff 临界压力比 IF Pc≤Pv: 0.68 ELSE 0.96-0.28·√(Pv/Pc) ff = 0.96 - 0.28·√(pv/pc)，补 Pc≤Pv 的 0.68 兜底（2026-09-04 P1-2） 已对齐 (2026-09-04)
阻塞判定 ΔP ≥ (Flp/Fp)²·(P1-Ff·Pv)（含 Fp/Flp 比） 实现 IEC Eq.20/30/33（2026-09-04 P1-1）：Fp=1/√(1+(K1+K2+KB1-KB2)·Cd²/N2)；Flp=FL/√(1+FL²·(K1+KB1)·Cd²/N2)；阻塞判定 dp ≥ flp²·(p1 - ff·pv)，Cv 用 cv_operating 单次迭代 已对齐 (2026-09-04)
Fr 雷诺数修正 完整实现 IEC Eq.28/G.1a/G.2/G.3a/G.4，含层流系数 n 完整实现 IEC Annex G (2026-09-04)：

4. 气体 Cv 计算

一致 气体 Cv 基本公式

来源公式
ExcelC = W / (31.6·Fp·Y·√(x·P1·ρ1)) (Kv+barA)
项目cv = mass_flow / (K_GAS · fp · Y · √(x_eff · p1 · density)) (Cv+kPa)
差异项Excel项目影响
压差比 x x = MIN(Fk·xTP, (P1-P2)/P1)（用 xTP 含管件修正） 实现 IEC Eq.33（2026-09-04 P1-1）：xTP = (xT/Fp²) / (1 + xT·(K1+KB1)·Cd²/N5')，x = (p1-p2)/p1; x_eff = min(x, Fγ·xTP)，用 cv_operating 单次迭代 已对齐 (2026-09-04)
膨胀系数 Y Y = 1 - x/(3·Fk·xTP) Y = 1 - x_eff/(3·Fγ·xt); Y = max(Y, 0.667) 一致 逻辑等价
压缩因子 Z Redlich-Kwong 状态方程 GasPTPcTcZ(P1,T1,Pc,Tc) Redlich-Kwong 状态方程 gas_compressibility_rk(P,T,Pc,Tc)（Cardano 三次方程，Vapor 根；对比态系数 Ωa=0.42747, Ωb=0.08664；水走 IAPWS） 已对齐 (2026-09-04)
入口密度 ρ1 ρ1 = Mw·P1 / (0.083143·Z·(T1+273.15))（含 Z） ρ1 = P·MW / (Z·8.314·(T+273.15))（Z 由 RK 计算；用户 override 密度时跳过） 已对齐 (2026-09-04)
声速 c c1 = (10⁵·k·P1/ρ1)^0.5 Newton-Laplace Newton-Laplace c = √(10⁵·γ·P/ρ1)（密度已含 Z，自动吸收压缩因子）。保留旧函数 gas_speed_of_sound 用于兼容。 已对齐 (2026-09-04)
标况体积流量修正 Excel 内部直接用 Qg(Nm³/s)，按理想气体转质量流量 units.py 实现 Nm³/h→工况 m³/h 修正：V_op = V_std×(101.325/P1)×(T1_K/T_std_K) 已对齐

已对齐 (2026-09-04) 两相流三种可切换模型并列（含 Annex C）

方法Excel项目
气液混合 (LiqGas) IEC 60534-2-1 Annex C：
C = 1/(31.6·Fp) × √[(Wf+Wg)·(Wf/(ρ1f·ΔPfe) + Wg/(ρ1g·Y²·ΔPge))]
分别计算液/气相有效压差 ΔPfe/ΔPge；Ff=0.96-0.28√(Pv/Pc)；阻塞分液/气两相判定 		三种可选模型（前端下拉可切换，默认叠加法）：

② 均相法 homogeneous：ρmix=1/(xg/ρg+xl/ρl)，代入气体膨胀方程
③ IEC Annex C (与Excel一致, 推荐)：使用项目 kPa 体系 K_LIQ=2.7351

ρ1fe = ρ1f/(1-Q), ρ1ge = ρ1g·Y²/Q

6. 管件修正 Fp / Flp / xTP

6.1 Fp 管件几何系数

来源公式判定
Excel Fp = 1 / √(1 + (K1+K2+KB1-KB2)·Cd²/0.00214)
K1 = IF(dv<D): 0.5·(1-(dv/D)²)² ELSE: (1-(D/dv)²)²/(D/dv)^4
K2 = 同结构（出口侧）
KB1/KB2 = 伯努利系数 1-(dv/D)^4 		完整 IEC Eq.20
项目 实现 IEC Eq.20（2026-09-04 P1-1）：
β = d/D
K1 = IF(d<D): 0.5·(1-β²)² ELSE: 0.5·(1-(D/d)²)²/(D/d)^4
K2 = 同结构
KB1=KB2 = 1-β^4
Fp = 1/√(1 + (K1+K2+KB1-KB2)·Cd²/N2)
N2 = 0.00214；仅 reduced_port=True 时计算 		已对齐 (2026-09-04)
对齐说明（2026-09-04 P1-1）：项目从原 ζ1=1.5/ζ2=1.0 固定系数近似，改为 IEC Eq.20 精确 K1/K2/KB1/KB2 分 dv<D / dv>D 两支计算。缩径比 β→1 时与原结果一致；β 偏离 1 时与 Excel 完全对齐。

6.2 Flp / xTP 带附件修正

参数Excel项目判定
Flp Flp = FL / √(1 + FL²·(K1+KB1)·Cd²/0.00214) (Eq.30) 实现 IEC Eq.30（2026-09-04 P1-1）：用户提供 flp → 直接用；缩径+几何 → Flp = FL/√(1+FL²·(K1+KB1)·Cd²/N2)；否则裸 FL 已对齐 (2026-09-04)
xTP xTP = xT/Fp² / (1 + xT·(K1+KB1)·Cd²/0.00241) (Eq.33) 实现 IEC Eq.33（2026-09-04 P1-1）：用户提供 xtp → 直接用；缩径+几何 → xTP = (xT/Fp²)/(1+xT·(K1+KB1)·Cd²/N5')，N5'=0.00241；否则裸 xT 已对齐 (2026-09-04)

7. 雷诺数与粘度修正 Fr

关键缺失 Fr 雷诺数修正未实现

Excel 完整实现：

Rev = 70.7·Fd·Qf / ((μ/ρ1)·√(Qf·(ρ1/(1000·ΔP))·Fl)·(FL²·Cd²/0.00214+1)^0.25)  ' Eq.28

' 层流系数 n
n = IF(Cd≥0.016: 0.00214/Cd², 1+127·Cd^(2/3))  ' Eq.G.1b/G.3b

' Fr 修正系数
Fr = IF(Rev<10: 0.026/Fl·√(n·Rev),
     MIN(1, 1+(0.33·√Fl/⁴√n)·LOG(Rev/10000),
         0.026/Fl·√(n·Rev)))  ' Eq.G.1a/G.2/G.3a/G.4

' 最终 Cv = C / Fr  (层流时 Cv 显著增大)

# cv_core.py
rev = ρ·U·(d/1000) / (μ_cp·1e-3)  # 仅计算雷诺数
if rev < 40:    return ("层流", "需 IEC Fr 修正")    # 仅提示

8.2 Excel 噪音五步法路径（完整）

Step 1: 压力比与流态判定 (5.1-5.2)
  x = (P1-P2)/P1                              ' Eq.1
  Pvc = P1·(1 - x/Flp²)                       ' Eq.2  缩脉压力
  xvcc = 1 - (2/(k+1))^(k/(k-1))              ' Eq.3  临界缩脉压差比
  xC = Flp²·xvcc                              ' Eq.4  临界压差比
  α = (1-xvcc)/(1-xC)                         ' Eq.5  恢复修正因子
  xB = 1 - (1/α)·(1/k)^(k/(k-1))             ' Eq.6  拐点压差比
  xCE = 1 - 1/(22·α)                          ' Eq.7  恒定声效率压差比
  RGM = IF(x≤xC:1, x≤xvcc:2, x≤xB:3, x≤xCE:4, 5)

Step 2: 几何参数 (5.3)
  Dj = 4.9×10⁻³·Fd·√(Cn·Flp)                 ' Eq.9  射流直径
  Fd = dh/do 或 1/√No                          ' Eq.8a 阀门类型修正

Step 3: 缩脉条件 (5.4-5.5)
  Mvc = √(2/(k-1)·((1-x/Flp²)^((1-k)/k)-1))  ' Eq.32 缩脉马赫数
  cvc = √(k·10⁵·P1/ρ1·(1-x/Flp²)^((k-1)/k))  '       缩脉声速
  Mj  = √(2/(k-1)·(MIN(22,1/(α·(1-x)))^((k-1)/k)-1)) ' 临界马赫数

Step 4: 声功率 (5.6)
  Wm = W/3600 × (cvc·Mvc)²/2     (Regime I)
  Wm = W/3600 × cvcc²/2           (Regime II-V)
  η  = 10^Aeta·Flp²·Mvc³          (I)
  η  = 10^Aeta·x/xvcc·Mj^(6.6·Flp²) (II)
  η  = 10^Aeta·Mj^(6.6·Flp²)      (III)
  η  = 10^Aeta·Mj²/2·√2^(6.6·Flp²) (IV,V)
  Wa = η × Wm                                 ' Eq.11

Step 5: 声压级与传递损失 (5.6)
  Lpi = 10·LOG(3.2×10⁹·Wa·ρ2·c2/D²) + Lg     ' Eq.18/31
  Lg  = 16·LOG(1/(1-MIN(0.3,Mp)))             ' Eq.16
  fp  = Stp·Mvc·cvc/Dj (I) / Stp·Mj·cvcc/Dj (II,III) / 1.4·Stp·cvcc/(Dj·√(Mj²-1)) (IV,V)
  fr  = 5000/(π·D)                            ' Eq.21 环频率
  fo  = fr·c2/(4·343)                         ' Eq.22 内部重合频率
  fg  = √3·343²/(π·t·5000)                    ' Eq.23 外部重合频率
  dTL = IF(D>0.15:0, D<0.05:9, 多项式)        ' Eq.20b
  Lpe1m = Lpi + TL(f) - 10·LOG((D+2t+2)/(D+2t)) + dLpAe  ' Eq.24
  最终 = MAX(75, Lpe1m - LaggingCredit - SpraywaterCredit)

8.3 项目噪音计算路径（简化）

T2  = T1·(p2/p1)^((γ-1)/γ)              # 等熵膨胀

Lwi  = 10·LOG(Wa/1e-12)                  # 声功率级
