> 版本：v2.0（基于 17 系列结构化数据全面修订）

## 一、总体架构

### 1.1 模块定位

选型模块作为现有 Cv 计算系统的**上游入口**：

```
工艺条件录入 → 规则引擎筛选候选 → 调用既有 calc/engine.py 反算 Cv 与开度
            → 按开度窗口排序输出推荐清单 → 选定后回填 ValveConfig + ProcessCase 进入精细计算
```

### 1.2 与既有系统的边界

**复用既有表**（不新增）：
- `valve_types`（系列字典）
- `valve_cv_stk`（额定Cv与行程，**唯一权威 Cv 数据源**）
- `valve_filter_config` / `valve_series_curve_config` / `valve_factor_curves` / `valve_sizing_indices`
- `nominal_size_refs` / `pipe_data` / `public_options` / `fluids`

**新增 4 张表**：
- `selection_rules`（选型规则库）
- `selection_records`（选型历史记录）
- `body_pt_ratings`（阀体材质温压限制）
- `allowable_pressure_drops`（最大允许压差）

**既有表增列**：
- `valve_cv_stk` 增加 `cv_min` FLOAT NULL

**复用计算引擎**：
- `backend/app/calc/engine.py` 做 Cv 反算与开度评估，不重复造轮子
- 介质物性一律查 `fluids` 表

## 三、数据校验与比对策略（v2 新增核心流程）

### 3.1 原则

- `valve_cv_stk` 为唯一权威 Cv 数据源，已有数据（从 CV&Stk.xlsx 导入）与新提取数据存在重叠
- 新提取数据用于**校验已有数据 → 标注差异 → 人工确认 → 以样本为准**
- 差异报告归档至 `docs/数据比对报告/` 供溯源

### 3.2 流程（每系列）

1. **读取 JSON**：通过 adapter 提取 `(series_code, dn_label, trim_label, flow_char, pressure_rating, seat_type) → rated_cv`
2. **查询库中对应**：按复合键匹配 `valve_cv_stk`，allowable 字段 NULL 时不参与匹配
3. **比对**：差异 > 5% 的行生成差异报告；差异 < 5% 自动跳过
4. **人工确认**：差异报告交用户确认，确认后 upsert
5. **新系列**：库中无数据 → 直接入库

### 3.3 adapter 设计

每个系列一个独立 adapter 文件：`backend/app/data_adapters/<series>_adapter.py`

```python
# 接口统一
class SeriesAdapter:
    series_code: str
    def parse_rated_cv(self, json_data) -> list[dict]: ...  # → [{dn_label, trim_label, flow_char, rated_cv, ...}]
    def parse_allowable_dp(self, json_data) -> list[dict]: ...
    def parse_body_pt(self, json_data) -> list[dict]: ...
    def parse_dimensions(self, json_data) -> list[dict]: ...
```

## 四、规则库分类与初始 seed 数据范围

### 4.1 规则分阶段执行

| 阶段 | category | priority | 动作 | 数量预估 |
|---|---|---|---|---|
| 1. 适用范围过滤 | scope | 10 | exclude | ~40条 |
| 2. 硬约束校核 | constraint | 20 | exclude/require | ~30条 |
| 3. 工况偏好加权 | preference | 30 | boost/penalty | ~20条 |
| 4. 后处理补字段 | post_filter | 40 | set_field/flag | ~10条 |

### 4.2 规则覆盖（按数据来源）

**A. 选型思路 PDF（~40条，全局规则）**
- 阀型决策树：直行程/角行程/开关阀/自力式分流
- 温度分档（-17~+230 / -45~-5 / >230 / -196~-45）→ 上阀盖形式约束
- 空化/闪蒸 → GC210/GC320 优先
- 禁铜 → 套筒材质约束
- NACE / 防火 → flag

**B. 各系列样本结构化数据（~60条，系列专属）**
- **GC120**: 最小口径 DN40；流向 Over plug；Md EQ% 仅全尺寸阀芯
- **GC210**: 最小口径 DN25；流向按介质区分；Fd 公式 `gc210_eqn`
- **GC320**: 高压差降噪优先；多孔套筒
- **GV120**: Large Cv P-port；fd_mode=eqn；流向/口径逻辑
- **GV110**: 直通单座；Linear 开度计算
- **GA510**: 角型阀；高温高压特殊工况
- **BT110/210/310**: 蝶阀；Cv 按角度（60°/90°）
- **BV130/210**: 球阀；金属座/软座 Cv 差异
- **GZ800**: 自力式；按介质（蒸汽/水/气体）
- **BT110**: 蝶阀适用大口径/高 dirt
- **BT310**: 高性能蝶阀；高温/高压差

**C. 开度窗口（~10条，post_filter）**

| 介质/动作 | Max | Nor | Min |
|---|---|---|---|
| 调节阀液体 | 85% | 60-80% | 20% |
| 调节阀气体 | 90% | 60-80% | 20% |
| 开关阀 | 90% | - | 30% |
| 蝶阀 60°~90° | 90% | 60-80% | 30% |
| 球阀 0°~90° | 90% | - | 30% |

## 九、关键工程约定

1. **复用优先**：Cv/开度反算一律走 `calc/engine.py`
2. **规则表达式禁任意求值**：仅 JSON 字典比较，未知键告警
3. **规则版本化**：更新 = 软删 + 新插；`applied_rule_ids` 可追溯
4. **统一建表**：所有规则、Cv、温压均统一表 + `series_code` 区分
5. **四大安全红线**：禁全表 DELETE / 禁凭据入文档 / 禁跳过校验 / 禁违反 series_code 唯一约束
6. **DDL 同步**：新增表后同步 `models/__init__.py` + `schemas/__init__.py`
7. **数据校验闭环**：新数据不入库即不生效，差异须经比对→确认→upsert 流程
8. **PDF 提取工作流**：PDF→docx→python-docx（已验证于全部 17 系列）
