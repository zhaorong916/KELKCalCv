## 一、设计目标与原则

### 1.1 设计目标

| # | 目标 | 度量 |
|---|---|---|
| 1 | **3 分钟完成一次选型**：从录入工艺到看到 Top3 候选 | 主工况录入 ≤ 12 个字段，1 次点击出结果 |
| 2 | **与 Calculation.vue 无缝衔接**：选中候选一键跳转精细计算 | apply 后 ValveConfig + ProcessCase(case_no=1) 自动回填 |
| 3 | **决策可追溯**：每个候选显示命中的规则、评分构成、开度窗口位置 | 行展开可见 applied_rules + score 构成 |
| 4 | **数据可沉淀**：每次选型自动保存快照 | `selection_records` 表完整记录 input_snapshot + candidates_json |

### 1.2 设计原则

1. **复用优先**：100% 复用 Calculation.vue 设计语言与 CSS 类（`page-card` / `section-card` / `form-grid` / `form-row` / `cases-table` / `metric` / `warnings-list` 等），零新增基础组件
2. **列宽约定**：严格遵循 160px 标签列 + 150px case 列既有约定
3. **单位统一**：内部统一 kPa(A) / ℃ / kg/h / mm，用户可选单位，提交前由前端完成换算
4. **单页双栏**：左右栏比例 0.85fr : 1.15fr，与 Calculation.vue 完全一致
5. **三种入口**：共享同一 `Selection.vue`，通过路由参数区分上下文
6. **MVP 收敛**：本阶段只做只读规则浏览，CRUD 留待 P5
7. **决策透明**：候选评分构成、命中规则、警告全部可见，不做"黑盒"

## 二、入口与上下文组织

### 2.1 三种入口对比

| 维度 | 入口 A：独立工作台 | 入口 B：位号上下文 | 入口 C：Calculation 内按钮 |
|---|---|---|---|
| **路由** | `/selection` | `/projects/:pid/valves/:vid/selection` | `/projects/:pid/valves/:vid/selection?from=calc&cid=<id>` |
| **路由 name** | `selection` | `valve-selection` | `valve-selection` |
| **菜单/触发** | MainLayout 快捷入口「阀门选型」 | ProjectDetail 位号行内「选型」按钮 | Calculation.vue Header 「从选型载入」按钮 |
| **项目/位号选择器** | 启用，需手工选择 | 禁用，由路由参数锁定 | 禁用，由路由参数锁定 |
| **是否预选位号** | 否 | 是 | 是 |
| **apply 后跳转** | `/projects/:pid/valves/:vid` | `/projects/:pid/valves/:vid` | 回到来源 Calculation.vue（带 `from=selection&record_id`） |
| **典型场景** | 项目早期无位号，自由探索 | 已有位号需重新选型或对比 | 计算中发现阀型不合适 |

### 2.2 上下文识别逻辑（Selection.vue `onMounted`）

```
if (route.params.pid && route.params.vid):
    mode = 'valve-context'   // 入口 B 或 C
    project_id = route.params.pid
    valve_id = route.params.vid
    Header 选择器禁用，显示当前位号 tag
elif (route.path === '/selection'):
    mode = 'standalone'      // 入口 A
    Header 选择器启用，默认空
```

### 2.3 入口 C 的完整流程

```
Calculation.vue                     Selection.vue                     Calculation.vue
     │                                   │                                   │
     │ 点击「从选型载入」                │                                   │

     │   selection?from=calc&cid=5       │                                   │
     ├──────────────────────────────────►│                                   │
     │                                   │ 录入工艺 → 运行选型 → 候选清单    │
     │                                   │ 点击「应用并跳转」                │
     │                                   │ POST /selection/records/:id/apply │
     │                                   │ 成功后路由回退                     │
     │                                   ├──────────────────────────────────►│
     │                                   │                                   │ onMounted 检测
     │                                   │                                   │ query.from='selection'
     │                                   │                                   │ → ElMessage.success
     │                                   │                                   │ → loadCalc() 重新加载
```

## 四、Header 设计

### 4.1 结构

复用 `.calc-header` 样式（白底卡片 + 左右 flex 布局），高度 48px，padding 10px 16px。

```
┌─ Header ─────────────────────────────────────────────────────────────┐
│ [HL] 项目选择器 位号选择器 [位号tag]  │ [HR] 历史 规则库 │ 运行选型 │
└───────────────────────────────────────────────────────────────────────┘
```

### 4.2 左区（HL）

| 元素 | 控件 | 数据来源 | 行为 |
|---|---|---|---|
| 项目选择器 | `el-select` filterable | `projectsApi.list()` | 选中后清空位号选择器并触发 `loadValves(pid)` |
| 位号选择器 | `el-select` filterable | `valvesApi.list(pid)` | 选中后写入 `valve_id` |
| 当前位号 tag | `el-tag` type=primary effect=dark | — | 显示 `tag_no`；位号上下文模式下替代下拉 |

### 4.3 右区（HR）

| 元素 | 控件 | 行为 |
|---|---|---|
| 历史记录按钮 | `el-button` icon=`Clock` | 打开历史记录抽屉（无 valve_id 时禁用） |
| 规则库按钮 | `el-button` icon=`Reading` | 跳转 `/selection-rules` |
| 分隔符 | 竖线 `\|` | 视觉分隔 |
| 运行选型按钮 | `el-button` type=success icon=`VideoPlay` | 触发 `runSelection()`； loading 时禁用 |

**禁用条件**：
- 入口 B/C 模式：项目/位号选择器禁用，显示当前 tag
- 必填项缺失（介质/流量/P1/P2）：运行按钮禁用 + tooltip 提示
- 运行中：运行按钮 loading

## 五、左栏：工艺条件输入

左栏容器复用 `.col-form`，包含 4 张卡片 + 顶部多工况 tab。

### 5.1 卡片 0：多工况切换 tab（新增，顶部）

- **控件**：`el-tabs` + `type="card"`，紧贴卡片 1 上方
- **结构**：

```
┌─ 卡片0 多工况 tab ──────────────────────────────┐
│ [★ 主工况] [工况 2] [工况 3]       [+ 添加工况] │
└──────────────────────────────────────────────────┘
```

- **行为**：
  - 最多 5 个 tab（与 Calculation.vue MAX=5 对齐）
  - 主工况永远在第 1 个 tab，标签前缀 ★ + 描边高亮
  - 切换 tab → 卡片 1、卡片 2 字段值切换到对应 case 快照
  - 卡片 3、卡片 4 **不切换**（位号级字段）
  - 「+ 添加工况」按钮：达到 5 个时禁用；新增 tab 默认复制主工况值
  - 非主工况 tab 右键或悬停显示「删除」按钮（主工况不可删）
- **状态**：`cases[]` 数组（响应式），`activeCaseIdx` 当前激活索引

### 5.2 卡片 1：介质与流态

复用 `.section-card` + `.form-grid`（1fr 1fr 双列网格）。

| 字段 | 控件 | 绑定 | 提交字段 | 说明 |
|---|---|---|---|---|
| 介质 | `el-select` filterable allow-create | `case.fluid_id` / `case.fluid_name` | `fluid_name` + `special_req.fluid_id` | 复用 `fluidsApi.list()`，参考 Calculation.vue L367 |
| 相态 | `el-radio-group` | `case.media` | `media` | 4 选项：liquid / gas / twophase / steam |
| 流态提示 | 只读 tag | `case.flow_regime` | — | 选型运行后由后端返回；未运行显示「—」 |

**介质下拉选项格式**：
```
{fluid_name_cn || fluid_name} ({formula}) [⚡ if is_water]
```
完全复用 Calculation.vue 的渲染规则。

**相态自动判定**：选中介质后，根据 `fluids.default_state` 自动填充；用户可手工覆盖。

### 5.3 卡片 2：工艺参数（当前工况）

复用 `.form-row` + `.label-with-unit` 模式（参数名左 + 单位下拉右 + 输入框），**单列布局**（非 form-grid 双列），保证单位下拉有充足宽度。

| 行 | 标签 | 单位下拉分组 | 绑定 | 提交字段 | 校验 |
|---|---|---|---|---|---|
| 1 | P1 阀前压力 | pressure (metric/imperial) | `case.p1` | `p1` (kPa) | > 0, > P2 |
| 2 | P2 阀后压力 | pressure | `case.p2` | `p2` (kPa) | ≥ 0, < P1 |
| 3 | ΔP 压差 | 只读徽章（不编辑） | computed | `dp` (kPa) | 自动 = P1 - P2 |
| 4 | T1 阀前温度 | temperature | `case.t1` | `t1` (℃) | -273 ~ 800 |
| 5 | 流量 | mass_flow / volume_flow / std_volume_flow（3 组） | `case.flow_rate` + `case.flow_rate_unit` | `flow_rate` + `flow_rate_unit` | > 0 |
| 6 | 管道尺寸 | diameter | `case.pipe_size` | `pipe_size` (mm) | > 0，可选 |

**单位下拉格式**（完全复用 Calculation.vue L387-394 模式）：

```html
<el-select v-model="caseUnits.p1" size="small" class="unit-select">
  <el-option-group label="公制">...metric units...</el-option-group>
  <el-option-group label="英制">...imperial units...</el-option-group>
</el-select>
```

**流量单位下拉特殊处理**：与 Calculation.vue L476-484 一致，先渲染「标况气体」组（`Nm³/h` 等），再渲染公制/英制。

**压力单位绝压/表压**：复用项目记忆中的「Pressure units must distinguish between absolute and gauge pressure, with automatic conversion」约定，内部统一转 kPa(A)。

### 5.4 卡片 3：阀门动作与泄漏（位号级）

不随工况 tab 切换，绑定到顶层 `form` 对象而非 `cases[i]`。

| 字段 | 控件 | 绑定 | 提交字段 |
|---|---|---|---|
| 阀门动作 | `el-radio-group` | `form.valve_action` | `valve_action`: `modulating` / `on_off` |
| 泄漏等级 | `el-select` | `form.leakage_class` | `leakage_class`: `IV` / `V` / `VI` |
| 可调比要求 | `el-input-number` (min=10, max=200, step=5) | `form.rangeability_required` | `rangeability_required` |
| 已知 Cv（可选） | `el-input-number` | `form.cv_required` | `cv_required`（填则跳过反算） |

### 5.5 卡片 4：特殊要求（位号级）

不随工况 tab 切换。

| 字段 | 控件 | 绑定 | 提交字段（`special_req` 内） |
|---|---|---|---|
| NACE MR0175 | `el-checkbox` | `form.special.nace` | `nace` |
| 防火安全 | `el-checkbox` | `form.special.fire_safe` | `fire_safe` |
| 禁铜 | `el-checkbox` | `form.special.copper_free` | `copper_free` |
| 低温 (<-45℃) | `el-checkbox` | `form.special.low_temp` | `low_temp`（T1 < -45 时自动勾选） |
| 高温 (>230℃) | `el-checkbox` | `form.special.high_temp` | `high_temp`（T1 > 230 时自动勾选） |
| 阀体材质 | `el-select` | `form.special.body_material` | `body_material` |
| 压力等级 | `el-select` | `form.special.pressure_class` | `pressure_class` |

**阀体材质选项**（从 `body_pt_ratings` 表 distinct 提取）：
- A216-WCB / A352-LCB / A351-CF8 / A351-CF8M / ZG230-450 / 304 / 316 / 316L

**压力等级选项**：
- ANSI: 150# / 300# / 600# / 900# / 1500# / 2500#
- PN: PN16 / PN25 / PN40 / PN63 / PN100

**自动勾选逻辑**：`watch(() => cases[0].t1)` → 根据温度自动勾选 `low_temp` / `high_temp`，用户可手工取消。

## 六、右栏：候选清单

右栏容器复用 `.col-result`，包含 4 个区块：概览条 / 候选清单表 / 警告列表。

### 6.1 概览条

复用 `.section-card`，单行 flex 布局：

```
┌─ 概览条 ──────────────────────────────────────────────────────┐
│ 共 8 个候选 · 命中 12 条规则 │ P1=2000kPa · Q=50t/h · T=80℃ │ [cavitation] │
└───────────────────────────────────────────────────────────────┘
```

| 区块 | 内容 | 数据源 |
|---|---|---|
| 左 | `共 N 个候选 · 命中 M 条规则` | `candidates.length` / `applied_rule_count` |
| 中 | 主工况摘要徽章 `P1=... Q=... T=...` | 当前 cases[0] 值 |
| 右 | 流态判定 tag | `candidates[0].flags.flow_regime`（多数决） |

**流态 tag 颜色**：
- `choked` 阻塞流：`type="warning"`
- `cavitation` 空化：`type="danger"`
- `flash` 闪蒸：`type="danger"`
- `normal` 正常：`type="success"`

### 6.2 候选清单表

复用 `el-table` + `border` + `size="small"`，列定义如下：

| 列 | prop | 宽度 | 对齐 | 渲染细节 |
|---|---|---|---|---|
| Rank | `rank` | 60px | center | 自定义徽章（#1 金 / #2 银 / #3 铜 / 其他数字） |
| 系列 | `series_code` + `series_name` | 140px | left | 两行：上行 `series_code` 粗体 13px，下行 `series_name` 灰色 11px |
| 口径/阀芯 | `dn_label` + `trim_label` | 110px | center | 单行 `40A / 25A` |

## 十四、错误码与告警文案

### 14.1 前端阻断（不入接口）

| 场景 | 触发条件 | 文案 | 级别 |
|---|---|---|---|
| 介质未选 | `!case.fluid_id && !case.fluid_name` | `请选择介质` | warning |
| 流量未填 | `!case.flow_rate` | `请填写流量` | warning |
| P1 未填 | `case.p1 == null` | `请填写阀前压力 P1` | warning |
| P2 未填 | `case.p2 == null` | `请填写阀后压力 P2` | warning |
| T1 未填 | `case.t1 == null` | `请填写阀前温度 T1` | warning |
| P1 ≤ P2 | `case.p1 <= case.p2` | `阀前压力 P1 必须大于阀后压力 P2` | error |
| 流量 ≤ 0 | `case.flow_rate <= 0` | `流量必须大于 0` | error |
| 未选位号 | `!valve_id` | `请先选择项目与位号` | warning |

### 14.2 后端告警（透传 warnings）

| 文案关键词 | 级别判定 | 前端样式 |
|---|---|---|
| 含「排除」「最小」「不满足」 | danger | `.warning-item.danger` |
| 含「超过」「缺少」「未知」 | warn | `.warning-item.warn` |
| 其他 | info | `.warning-item.info` |

**典型文案示例**：
- `GC120 最小口径 DN40，当前 DN25 已排除` → danger
- `GC210 100A/80A 缺少 cv_min，可调比未知` → warn
- `GC210 压差 1.500 MPa 超过允许压差上限 1.000 MPa` → warn
- `未匹配到介质物性，采用通用兜底` → info
- `GC210 100A/80A 曲线解析失败: HTTPException(404)` → warn

### 14.3 网络/接口异常

| HTTP 状态 | 处理 | 文案 |
|---|---|---|
| 400 | ElMessage.error | `请求参数错误: {detail}` |
| 404 | ElMessage.error | `选型记录不存在或已删除` |
| 422 | ElMessage.error | `字段校验失败: {detail[0].msg}` |
| 500 | ElMessage.error | `服务器异常，请稍后重试` |
| 网络超时 | ElMessage.error | `网络异常，请检查连接` |

### 14.4 apply 冲突

| 场景 | 处理 |
|---|---|
| 目标位号已有手工配置 | `ElMessageBox.confirm('当前位号已有手工配置，应用选型将覆盖阀门配置与工况 1，是否继续？')` |
| 重复 apply 同一记录 | 后端幂等（更新而非插入），前端 `ElMessage.info('该选型已应用，已更新配置')` |
