## 一、核对方法

1. PDF 为唯一权威数据源。p2/p12/p13 有文字层（`pdfplumber` 坐标化提取），p1 为封面（少量文字层），p3~p11 全部文字转曲（`pypdfium2` 渲染 PNG 图像识别）。
2. docx 18 表全部由 OCR 重建，逐格与 PDF 比对：一致采信；不一致以 PDF 为准并更正；docx 缺漏内容按 PDF 补入。
3. 页号换算：PDF 页 = 印刷页 + 2（印刷页 1 对应 PDF p3）。
4. 高密度尺寸表（表12/13）在临时目录裁剪放大 1.9 倍复核（`gv110_crop/page_10_dims.png`、`page_11_dims.png`）；表3、表5 裁剪放大 2.2/1.9 倍复核。

- 表12/13（正/反作用 PD3000LA 尺寸表，各 6 行×21 列）经 1.9 倍放大图逐格核对，**全部数值与 docx 一致**（含 L 七列、H2、h1/H1 标准与散热、A/B/L1/L2/W、型号、H；正反作用的 H1 与 L2 区间差异为真实差异）。

- 每个口径对应两支执行机构（218→PD3021LA、270→PD3027LA），标准型/散热片型上阀盖 H1 与 A/B/L1/L2/W 随执行机构变化。
- 正作用 H1 标准=430/525、散热=530/625，L2=133~113 / 155~135；反作用 H1 标准=470/565、散热=570/665，L2=113~133 / 118~138。

### 原文档自身问题（如实保留并标注，非 docx 差异）
- p4 阀内件"填料"说明引用「图4 (See Fig.4)」，但本样本填料温度·压力范围图为「图2」，疑为原文引用笔误（PDF 原文即如此，保留原样）。
- 附表三 中国标准牌号 `ZG0Cr18nI9` 系原文档错别字（正确应为 ZG0Cr18Ni9）：渲染图与 pdfplumber 文字层均确认 PDF 原文即如此，保留原样。

### OCR 错别字清单（仅文字，不影响数值；structured_data 相关字段已更正）
- 单位/符号：`它`/`七` → **℃**
- 口径：`1/2"~I"` → **1/2"~1"**（I→1）；尺寸表 inch 空 → **1**
- 材质：`A35 l-CF8 / A35 l-CF8M` → **A351-CF8 / A351-CF8M**；`ZG0Cr18nI9`（原文即错，保留）
- 压力：`PNI.6MPa` → **PN1.6MPa**；`PNI O.OMPa` → **PN10.0MPa**
- 数值：`0.0l 5` → **0.015**
- 零件：`压胆` → **压圈(Pressing ring)**；`防尘圆` → **防尘圈(Wiper)**；`阀座Seatgasket` → **阀座 Seat gasket**；`l6` → **16**
- 填料：`聚四颌乙烯`/`聚四抓乙烯`/`聚四娠乙烯`/`聚四撤乙烯` → **聚四氟乙烯**；`禁汕` → **禁油**
- 附件：`电气气气智能定位器` → **电/气、电气智能定位器**
- 表头：`hl` → **h1**、`Hl` → **H1**、`Ll` → **L1**、`.mch` → **inch**
