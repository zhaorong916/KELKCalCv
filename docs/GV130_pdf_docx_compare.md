## 一、核对方法

1. PDF 为唯一权威数据源。p1 封面/p2 公司介绍/p19 附表/p20 联系方式有文字层（`pdfplumber` 坐标化提取，直接采信）；p3~p18 全部文字转曲（`text_len=0`），由 pypdfium2 渲染 PNG 图像识别。
2. docx 26 表全部由 OCR 重建，逐格与 PDF 比对：一致采信；不一致以 PDF 为准并更正；docx 缺漏内容按 PDF 补入。
3. 页码换算：PDF 页 = 印刷页 + 2（封面为 PDF p1、印刷页码自 PDF p3 起计为 1）。
4. 高密度表（表3 额定Cv、表4-1/4-2 允许压差、表5 重量、六张尺寸表）均在临时目录裁剪放大 2.0 倍后复核，字迹清晰、数值可辨。

## 三、逐表核对结论

### 数值完全一致（采信 docx，仅下列 OCR 错字，无数据改动）
表0-5（标准规格、执行机构、控制附件、特殊规格）、**表6/表7（表2-1碳钢/表2-2不锈钢材质组合，6列组合与各温度区间全部一致）**、表9（表3 额定Cv及行程 9行全对）、表10（表4-1）、表11（表4-2）、表12（表5-1本体部重量）、表13（表5-2执行机构重量）、表17/18（304LLA-D/R 尺寸 3行）、表19（306SLA-D 2行）、表20/21（306LLA-D/R 尺寸）、表22（附表一 ANSI 温压 18行×18列全对）、表23（附表一 JB PN 温压）、表24（附表二 公称压力对照）、表25（附表三 常用材质对照）。

### PDF 确认的特殊事实
- **p6 表1-1 结构清单为 23 项**（docx 无任何 23 行表，确属漏表）；其中 No.3 中/英为「阀座 / Seat gasket」、No.4「平衡密封环 / Balance seal」、No.22「密封圈 / Sealing ring」，PDF 原文如此。
- **306SLA 正/反作用（p15/p16）尺寸数值在 PDF 上完全相同**（2行×全部列一致），docx 只有 1 张 306SLA 表并非数值错误。
- **306LLA 正/反作用（p17/p18）同样完全相同**（8(200) 单行）。
- 304LLA 正/反作用（p13/p14）**H1 与 L2 不同**：如 5(125) 正作用 H1标准=920/H1散热=1070、L2=260~210，反作用 H1标准=960/H1散热=1110、L2=161~211，系真实差异。
- 306SLA/306LLA 尺寸表含标准型/散热片型上阀盖的 **H3/H4 列**，无 L1/L2/W 列；304LLA 尺寸表则为 A/B/L1/L2/W 列。
- 附表二「公称压力对照表」中国标准栏为合并单元格 `PN 63, PN 100`；附表三美国标准末列 PDF 文字层确为 `A352-LCB`。
