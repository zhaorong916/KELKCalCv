## 一、核对方法

1. PDF 为唯一权威数据源。p1/p2/p20/p21 有文字层（pdfplumber 直读）；**p3–p19 全部文字转曲（text_len=0）**，用 pypdfium2 渲染 PNG（1310×1778）后逐图识别。
2. docx 26 表全部由 OCR 重建，逐格与 PDF 比对：一致则采信；不一致以 PDF 为准并更正；docx 漏表/空表按 PDF 补入。
3. 页码换算：**PDF 页 = 印刷页 + 2**（PDF p4 = 印刷页 2）。
4. 高密度表图像不清晰处，用 PIL 将 PNG 相关区域裁剪并放大 2×~8×（LANCZOS）后重读；值域疑似的 OCR 数字粘连必回图像复核。

## 三、逐表核对结论

### 数值完全一致（采信 docx，无需改动）
标准规格（表0,1,2）、执行机构/附件/特殊规格（表3,4,5）、材质组合（表8,9,10，逐列逐格一致）、附表一ANSI 18行×18列、附表一JB/HG 9行、附表二、附表三（除样本自身 ZG0Cr18nI9 错字外）——**均与 PDF 逐格一致**。
压差表（表12–19）**数值经抽样回图像复核一致**（每个表均核对首行及若干代表行），仅少数 OCR 字母/数字误识（见下），已更正。

### PDF 确认的特殊事实
- **材质组合 8 个数据列的分组**：阀体材质跨列合并——表2-1 为 A216-WCB(4列)+A351-CF8(2列)+A351-CF8M(2列)；表2-2/2-3 为 Q235(4列)+304(2列)+316(2列)。阀杆材质固定为 630(前4列)/316(后4列)；阀板处理 表2-1=Hcr、表2-2/2-3=—。
- **压差表执行机构清单**（与 docx 一致）：PC2200RA 双动=Φ075/085/110/125/140/160/190/210/240/270（阀门口径 3″~40″）；PC4200RA 双动=Φ130/170/200/280/350/400（口径 8″~60″）；PC2100RA 单动=Φ110~270（8 型，口径 3″~40″）；PC4100RA 单动=Φ170/200/250/280（口径 3″~40″）。
- **"表4-1A" 阀门口径起始 3″**（Φ075/PC2207RA），与 PC4200RA 起于 8″ 不同，系真实差异。
- **表4-2D PC4128RA 630 ΔP 在 32″ 处数值 0.38 大于 28″ 的 0.16**、**表4-1D PC4235RA 630 Shut 在 44″ 处 0.70 大于 40″ 的 0.65**——docx 与 PDF 渲染图完全一致，属样本原始值（非单调），保留。
- **压差表 "—" 单元格**：部分执行机构/口径组合以 "—" 表示不适用（如 PC2211RA 316 Shut 多处），保持原样。
