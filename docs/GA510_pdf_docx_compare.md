## 一、核对方法

1. PDF 为唯一权威数据源；p1/p2/p20/p21 有文字层（pdfplumber 坐标化提取），p3–p19 全部文字转曲（pypdfium2 渲染 PNG 图像识别）。
2. docx 27 表全部由 OCR 重建，逐格与 PDF 比对：一致采信；不一致以 PDF 为准并更正；docx 缺漏内容按 PDF 补入。
3. 页码换算：PDF 页 = 印刷页 + 2。
4. 高密度转曲页（p8 额定Cv、p9 允许压差）用 PIL 裁剪放大 1.8~2 倍后重读；p9 用 numpy 检测表格网格线（垂直 x 坐标）精确对齐 13 个阀芯尺寸列。
5. 原文档自身瑕疵（中英矛盾、错别字）如实保留并标注，不计入 docx 差异。

### PDF 确认的特殊事实
- 表21 与表22（PD306LLA 正/反作用）尺寸数值在 PDF 上完全相同，仅执行机构作用方式不同。
- `size_hd_profile`（h1~h4 / d1~d3）仅取决于阀口径，与执行机构无关，已在 sizes 段单列。
- PD304ELA、PD306SLA 表列结构与 PD3000LA 略异（无 handle 列 / 无 L600 列），已按 PDF 列结构建表。

### 原文档自身问题（保留原样并标注）
