## 一、结论摘要

用户点名的三类问题全部成立，且根因一致：**把样本中"按条件分档"的参数，压平成了系列级单一区间**。

| 类别 | 确认结果 | 涉及规则数 |
|---|---|---|
| 1. 条件未考虑未选定属性（上阀盖/轴承型） | 成立。GC120/210/320、GV110/120/130、BT110/210/310 的温度规则均把各上阀盖档位的并集当成系列区间 | scope 温度规则 22 条 |
| 2. 温度限与材质搭配 | 成立。GC120/210/320、GV110/120、BT110、BV130、GZ800 样本的使用温度按"阀体+阀内件/密封/填料组合"分列，规则未带材质条件 | 待新增/改造约 20 条 |
| 3. 阈值单位/换算口径 | 成立且影响最大。`p1_max` 在上文中是 **kPa(A)**，规则阈值却写成 `1.6/4.0/6.3/10.0`（MPa 口径），导致这些约束对几乎所有工况恒真 → 该系列被无条件排除 | constraint 13 条 |

复查中另发现 5 类问题（不在点名范围，但同属"对样本解读错误"）：

| # | 问题 | 例子 |
|---|---|---|
| A | 泄漏等级规则与样本相反 | `R-CON-BT310-002` 要求 Class IV 时排除 BT310，但样本 BT310 提供 **Class V/VI**；`R-CON-GC320-002` 要求 Class VI 时排除 GC320，但样本 GC320 **可选 Class VI** |
| B | 目标系列不存在或张冠李戴 | `R-PREF-GLOBAL-014` 目标是 `GZ840`，但 `GZ840` 是 GZ800 系列下的**型号**，不是独立系列 |
| C | 空化/闪蒸：方案写"优先"，规则做成"排除" | `R-CON-GC120-001`、`R-CON-GV110-001`、`R-CON-GA510-001`、`R-CON-GLOBAL-001` |

## 二、样本事实（用于逐条比对）

### 2.1 上阀盖/轴承型温度分档（原文）

| 系列 | 分档 | 样本值 | 出处 |
|---|---|---|---|
| GC120 / GC210 / GC320 | 标准型 | -17~+230℃ | GC120_210_structured_data.json `general_data.bonnet`；GC320 同 |
| 同上 | 散热片型 | -45~-5℃ **或 > +230℃** | 同上 |
| 同上 | 加长型 | -196~-45℃ | 同上 |
| GV110 / GV120 / GV130 | 标准型 / 散热片型 / 加长型 | 同上三档 | GV110/GV120/GV130_structured_data.json `general_data.bonnet` |
| GV120 | 波纹管密封型 | "使用温度、压力范围见图2-3、图2-4"（无数值） | 同上 |
| GV120 | 蒸汽夹套型 | "-5~+230℃以上" | 同上 |
| BT110 | 内部轴承型 | -5~+200℃（仅 DN80~DN550） | BT110_structured_data.json `bearing_type_for_stem` |
| BT110 | 外部轴承型 | -5~+600℃（>600~1000 可特殊设计） | 同上 |
| BT210 | 标准型 | -45~+500℃ | BT210_structured_data.json `general_data.bonnet` |
| BT210 | 加长型 | -196~+100℃ | 同上 |
| BT310 | 标准型 / 外部轴承型 / 散热片型 | -45~+200 / -45~+600 / +600~+1000℃ | BT310_structured_data.json `bearing_type_for_stem` |

**关键点**：这些档位是**互斥区间**，不存在一个上阀盖能覆盖 -196~+230℃。现行规则取"最小下限 + 最大上限"（如 GC120 = -196~230），既错误排除了散热片型的 >230℃ 工况，又错误放行了"加长型 + 100℃"这类不存在的组合。

### 2.2 温度与材质/填料组合（原文摘录）

- GC120/210（`GC120_210_样本基础数据分析.md` L155-195）：表2 按"阀体材质 + 阀内件/密封环/填料"组合列使用温度，例如碳钢 + PTFE 约 -5~+230℃，碳钢 + 柔性石墨/司太莱可到 425/538℃，不锈钢 + PTFE -196~+230℃、+SF 到 538℃。
- GV110/GV120：表2-1（碳钢）、表2-2（不锈钢）逐列给使用温度，并注明"流体温度 -80℃ 以下软密封阀芯为 Kel-F"。
- BT110：附表1 和表2-3 按阀体材质 + 轴承型 + 填料分列；≥400℃ 须不锈钢阀内件。
- BV130：附表一按 ANSI Class 150/300/600 × 6 种阀体材质给温压表。
- GA510：样本注明"必须注意各材质的使用温度"，未给单一数值。
- GZ800：不同型号（GZ810~GZ880）温度不同，多数 -48~+300℃，部分 -48~+120℃。

结论：**温度上限不是系列常量，至少是"上阀盖/轴承型 × 阀体材质（× 密封/填料）"的函数**。现行规则缺这两个维度。

### 2.3 压力/压差口径

- 引擎内部单位（`selector._base_ctx`）：温度 ℃、压力 **kPa(A)**、压差 **kPa**、口径 **mm**、Cv 无量纲。
- 样本给的是 **MPa G**（`body_rating`：PN1.6/4.0/6.3/10.0；ANSI 150/300/600#）与"最大允许压差 MPa"。
- 现行 13 条 `p1_max` 约束直接把 MPa 数字写进 kPa 上下文 → `4100 > 10.0` 恒真。

### 2.4 泄漏等级

| 系列 | 样本可选泄漏等级 | 现行相关规则 | 判定 |
|---|---|---|---|
| BT310 | ANSI Class **V、VI** | `R-CON-BT310-002`：leakage=IV 时排除 | 错误（应删除） |
| GC320 | Class **IV、VI**（软/金属阀座） | `R-CON-GC320-002`：leakage=VI 时排除 | 错误（应删除） |
| GV110 | Class IV（可选 V） | `R-CON-GV110-002`：leakage=VI 时排除 | 正确（保留） |

## 三、重写原则（拟）

1. **不引入任意表达式**：仍只用现有算子 `_eq/_ne/_min/_max/_gt/_lt/_required/_or`。
2. **依赖属性缺失 → 规则不命中**：条件里显式带上 `bonnet_form` / `body_material`，属性为空时 `_eq` 自然为假，不做排除。值域复用阀体参数卡片，不新增"轴承型式"字段（并入 `bonnet_form`）。
3. **缺失依赖属性时给提示而非排除**：用 post_filter `flag` 规则标记"需确认上阀盖型式/材质"，由前端展示。
4. **单位统一为引擎内部单位**：压力/压差一律 kPa，温度 ℃，口径 mm。
5. **rule_code 不改格式**：仍由 `_generate_rule_code` 按"类别+系列"递增；新版本沿用原 code、`version+1`（需表结构支持，见 §五）。
6. **软删除**：旧版本 `is_active=false`，插入新版本；不做全表 DELETE；有 `selection_records.applied_rule_ids` 引用的规则只停用不删除（当前 0 条记录、0 引用）。

## 六、待人工确认清单（压缩版，逐条给推荐值）

> Q2 已决：直接复用阀体参数卡片字段（阀体+阀芯+阀座+套筒+平衡密封+填料），按 `body_material_group` 分档。
> Q9 已决：`p1_max` 统一用 `pressure_class` 判定，`pressure_rating` 只查曲线系数（见决定 D4）。

**Q1 散热片型温度上限** → 建议：不设绝对上限，按所选材质查 `body_pt_ratings` 截断；未选材质时只提示、不排除。
影响：写死 230 会再次误杀散热片型高温工况；完全不设则可能选出超材质温限组合，需靠材质规则兜底。

**Q3 GC120/210/320 口径下限** → 建议：取 DN40（额定 Cv 表起点）。
影响：取 DN25 会生成无 Cv 数据的候选或空结果；取 DN40 会漏掉未来补充的 DN25/32 阀芯（当前无数据）。

**Q4 空化/闪蒸判定方式** → 建议：改为优先加分（保留 GC210/GC320 加分），不硬排除。
影响：硬排除会让蝶/球/角阀在空化工况全部消失（PV-4106a 即 0 候选）；全改优先可能放宽阀型，需靠打分排序收敛。

**Q5 GA510 压力上限** → 建议：按 `pressure_class` 查材质温压表，不写死 PN6.3。
影响：写死 PN6.3 会误杀 ANSI 600# 工况；不限制则高压下可能超阀体额定。

**Q6 BT210 压力上限** → 建议：按 `pressure_class` 区分（ANSI 300# 约 5.1 MPa）。
影响：写死 4.0 MPa 会误杀 300# 工况；放开则需确保 150# 工况仍被正确限制。

**Q7 GZ800 型号级温限** → 建议：系列级按 300℃，`GZ840` 规则改挂 GZ800；型号级（120℃）暂不建规则。
影响：不做型号级会放宽 GZ840 高温工况；建型号级则需新增型号字段，超出本次"复用现有字段"范围。

**Q8 开关阀开度惩罚** → 建议：停用 `R-POST-OPEN-005/006`。
影响：保留会把正常全开/全关的开关阀扣分，导致排序失真；停用后开关阀只按泄漏与压差排序。

**Q10 波纹管密封型/蒸汽夹套型温度** → 建议：暂不建数值规则，选中时提示查图。
影响：自造数值风险高；不建规则则这两类结构不受温度排除，可能选到超温组合。

**Q11 GZ800 阻塞/临界流排除** → 建议：停用（样本无依据）。
影响：保留会误杀可用工况；停用后临界流工况可能选出不合适阀型，由 warning 提示。

**Q12 GV120/GV130 可调比 ≥50** → 建议：先停用，待样本可调比表补齐再启用。
影响：启用可能误杀；停用则高可调比需求无法参与排序。
