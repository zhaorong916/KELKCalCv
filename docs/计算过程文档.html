3. 介质物性计算¶

3.1 水/水蒸汽（IAPWS-IF97，[properties.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/properties.py) L64-124）¶

相态自动判定逻辑：

输入: 温度 T(℃), 压力 P(kPa abs)
1. 计算饱和蒸汽压 Psat = _PSat_T(T+273.15) × 1000   [kPa]   (IAPWS-IF97 Region 4)
2. 容差 tol = max(0.5, Psat × 0.002)
3. 判定:
     |P - Psat| ≤ tol  →  saturated（饱和）
     P > Psat          →  liquid（液态，过冷水）
     P < Psat          →  gas（过热蒸汽）

物性取值：

  • 液态/过热蒸汽：调用 IAPWS97(P=P/1000, T=T+273.15) 取 ρ、μ、γ=cp/cv、w（声速）

  • 饱和：取气相代表性值 IAPWS97(P=P/1000, x=0.5).Vapor（密度、粘度、比热比、声速）

  • 粘度单位转换：Pa·s → cP（×1000）

  • 兜底：iapws 库不可用时使用近似公式（L147-184），精度较低

关键常数：

  • 水临界压力 Pc = 22064 kPa(abs)

  • 水临界温度 Tc = 373.946 ℃

  • 水摩尔质量 M = 18.015 kg/kmol

3.2 通用气体密度（[properties.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/properties.py) L130-134）¶

理想气体状态方程：

ρ = P × M / (Z × R × T)

其中:
  P: kPa(abs)
  M: kg/kmol
  R = 8.314 kPa·m³/(kmol·K)
  T = t + 273.15 K
  Z: 压缩因子（默认 1.0）

3.3 气体声速（[properties.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/properties.py) L137-141）¶

c = √(γ × R' × T)

其中:
  R' = 8314 / M   J/(kg·K)
  T = t + 273.15 K
  γ: 比热比 cp/cv

3.4 介质库默认值（[properties.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/properties.py) L192-214）¶

4. 阀门系数工具¶

4.1 管件几何系数 Fp（[cv_core.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_core.py) L76-99）¶

IEC 60534-2-1 Eq.5/6：

Fp = 1 / √(1 + ζ × (Cv / (N2 × d²))²)

其中:
  ζ = ζ1 + ζ2          (进出口管件阻力系数之和)
  ζ1 = 1.5 × (1 - β²)²  (进口缩径，突变缩阻力系数近似)
  ζ2 = 1.0 × (1 - β²)²  (出口扩径，突变扩阻力系数近似)
  β = d / D             (阀座口径/管道内径)
  N2 = 0.00214          (d 单位 mm)

取值规则：

  • 用户直接提供 fp → 采用录入值

  • 非缩径（reduced_port=False）或缺少几何尺寸 → Fp = 1.0

  • β ≥ 0.999 → Fp = 1.0

  • Fp 限幅 [0.1, 1.0]

修订要点：当前 ζ1/ζ2 采用突变缩/扩近似，IEC 标准对渐缩 reducer 有更精确公式。若需精化，替换 L95-97 的 ζ 计算。

4.2 有效液体压力恢复系数 FL（[cv_core.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_core.py) L102-107）¶

带附件: FL_eff = FLp   (用户提供时采用)
无附件: FL_eff = FL    (默认 0.9)

4.3 有效临界压差比 xT（[cv_core.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_core.py) L110-114）¶

带附件: xT_eff = xTp   (用户提供时采用)
无附件: xT_eff = xT    (默认 0.72)

4.4 雷诺数（[cv_core.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_core.py) L117-130）¶

基于阀座口径特征流速：

A = π × d² / 4 × 10⁻⁶        [m²]   (mm² → m²)
U = (ṁ / 3600) / (ρ × A)      [m/s]  (kg/h → kg/s)
Rev = ρ × U × (d/1000) / μ    [无量纲]

其中:
  d: 阀座口径 mm
  ṁ: 质量流量 kg/h
  μ: 动力粘度 Pa·s (= cP × 10⁻³)

4.5 雷诺数修正判定（[cv_core.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_core.py) L133-141）¶

雷诺数范围 判定 处理
Rev < 40 层流区 提示需 IEC 粘度修正 Fr
40 ≤ Rev < 3000 过渡区 提示 Fr 可能有效
Rev ≥ 3000 湍流区 无需修正

修订要点：当前仅给出提示，未实际执行 Fr 修正。如需实现，参考 IEC 60534-2-1 Eq.1 Fr 计算式。

5. 液体 Cv 计算¶

源码：[cv_liquid.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_liquid.py) 标准：IEC 60534-2-1 / GB/T 17213.2

5.1 基本方程（非阻塞湍流）¶

体积流量形式：

Q = K_LIQ × Fp × Cv × √(ΔP / ρ)                         ... (IEC Eq.6)

质量流量形式（引擎实际使用）：

W = K_LIQ × Fp × Cv × √(ΔP × ρ)                         ... (IEC Eq.7)
→ Cv = W / (K_LIQ × Fp × √(ΔP × ρ))

5.2 阻塞流判定（IEC Eq.3）¶

液体临界压力比系数：

FF = 0.96 - 0.28 × √(Pv / Pc)                           ... (IEC Eq.4)

其中:
  Pv: 介质饱和蒸汽压 kPa(abs)
  Pc: 介质临界压力 kPa(abs)（水 22064）
  FF 限幅 [0, 1]

临界压差：

ΔPch = FL² × (P1 - FF × Pv)                              ... (IEC Eq.3)

阻塞判定：

若 ΔP ≥ ΔPch → 阻塞流，计算采用 ΔP_eff = ΔPch
否则         → 非阻塞，ΔP_eff = ΔP

5.3 Cv 计算（[cv_liquid.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_liquid.py) L79-86）¶

Cv = W / (K_LIQ × Fp × √(ΔP_eff × ρ))

5.4 流态判定（[cv_liquid.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_liquid.py) L114-122）¶

条件 流态 说明
非阻塞 非阻塞(湍流) 正常流动
阻塞 + P2 ≤ Pv 阻塞流-闪蒸 阀后压力低于饱和蒸汽压，液体闪蒸为气体
阻塞 + P2 > Pv 阻塞流-空化 阀内喉部压力低于 Pv 产生气泡，阀外 P2>Pv 气泡溃灭

5.5 开度计算¶

开度% = (Cv_required / Cv_rated) × 100%

  • Cv_rated = 用户选用额定 Cv（rated_cv_select）或阀门额定 Cv

  • 若开度 > 100% → 警告"阀门偏小"

5.6 算例（水-正常工况）¶

输入: P1=680, P2=220 kPa, T=25℃, W=120000 kg/h, ρ=1000, FL=0.9
计算:
  ΔP = 460 kPa
  Pv(25℃) ≈ 3.17 kPa, Pc=22064 kPa
  FF = 0.96 - 0.28×√(3.17/22064) = 0.950
  ΔPch = 0.9² × (680 - 0.950×3.17) = 551.4 kPa
  ΔP(460) < ΔPch(551.4) → 非阻塞
  Cv = 120000 / (2.7351 × 1.0 × √(460 × 1000)) = 64.78 ✓

6. 气体/蒸汽 Cv 计算¶

源码：[cv_gas.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_gas.py) 标准：IEC 60534-2-1 膨胀系数法

6.1 基本方程（质量流量）¶

W = K_GAS × Fp × Cv × Y × √(x × P1 × ρ1)               ... (IEC Eq.11)
→ Cv = W / (K_GAS × Fp × Y × √(x × P1 × ρ1))

6.2 压差比与膨胀系数¶

x = ΔP / P1                                              压差比
Fγ = γ / 1.4                                             比热比系数
xT_eff = Fγ × xT                                         有效临界压差比
Y = 1 - x / (3 × Fγ × xT)                               膨胀系数

  • Y 下限 = 0.667（临界状态）

  • γ: 比热比 cp/cv（空气 1.4，过热蒸汽 1.327，饱和蒸汽 1.135）

6.3 临界（阻塞）流判定¶

若 x ≥ Fγ × xT → 临界(阻塞)，取 x_eff = Fγ × xT, Y = 0.667
否则           → 亚临界(非阻塞)，x_eff = x

6.4 Cv 计算（[cv_gas.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_gas.py) L69-81）¶

Cv = W / (K_GAS × Fp × Y × √(x_eff × P1 × ρ1))

6.5 算例（过热蒸汽工况）¶

输入: P1=1500, P2=800 kPa, T=200℃, W=5000 kg/h
      水(IAPWS自动判定为gas), ρ1≈3.96 kg/m³(由IF97), γ≈1.327, xT=0.72
计算:
  ΔP = 700 kPa
  x = 700/1500 = 0.4667
  Fγ = 1.327/1.4 = 0.9479
  xT_eff = 0.9479 × 0.72 = 0.6825
  x(0.4667) < xT_eff(0.6825) → 亚临界
  Y = 1 - 0.4667/(3×0.6825) = 0.790
  Cv = 5000 / (2.7330 × 1.0 × 0.790 × √(0.4667×1500×3.96)) = 31.86 ✓

7. 两相流 Cv 计算¶

源码：[cv_twophase.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/cv_twophase.py) 说明：IEC 60534-2-1 未给出单一标准方程，本系统提供两种工程方法。

7.1 质量含气率¶

x_g = m_gas / (m_gas + m_liquid)

7.2 方法 A：叠加法（默认，additive）¶

气相与液相分别按各自公式计算 Cv，再相加：

Cv_gas = m_gas / (K_GAS × Fp × Y × √(x_eff × P1 × ρ_gas))
Cv_liquid = m_liquid / (K_LIQ × Fp × √(ΔP × ρ_liquid))
Cv = Cv_gas + Cv_liquid

  • 气相：用膨胀系数法（Y、x_eff 同气体计算）

  • 液相：用非阻塞近似（全 ΔP）

  • 适用：气液混合、不凝气夹带液体；保守、工程常用

7.3 方法 B：均相膨胀系数法（homogeneous）¶

按均相混合密度处理，采用气体方程：

ρ_mix = 1 / (x_g/ρ_gas + (1-x_g)/ρ_liquid)              均相混合密度
Cv = (m_gas + m_liquid) / (K_GAS × Fp × Y × √(x_eff × P1 × ρ_mix))

  • Y 与 xT 取气相参数

  • 适用：湿气为主、相间平衡的工况

7.4 流态判定¶

条件 流态
x ≥ Fγ×xT 临界(阻塞)-叠加 / 临界(阻塞)-均相
x < Fγ×xT 亚临界-叠加 / 亚临界-均相

7.5 算例（气液两相）¶

输入: P1=600, P2=400 kPa, m_gas=5000, m_liquid=2000 kg/h
      ρ_gas=6.96, ρ_liquid=1000, γ=1.4, xT=0.72
方法: additive
计算:
  x = 200/600 = 0.3333
  Fγ = 1.4/1.4 = 1.0
  xT_eff = 0.72, x(0.333) < 0.72 → 亚临界
  Y = 1 - 0.333/(3×0.72) = 0.846
  Cv_gas = 5000/(2.733×1×0.846×√(0.333×600×6.96)) = 50.51
  Cv_liquid = 2000/(2.7351×1×√(200×1000)) = 16.24
  Cv = 50.51 + 16.24 = 59.62 ✓（代码输出 59.62，亚临界-叠加）

修订要点：叠加法为保守估算，对闪蒸流动（液体减压闪蒸为蒸汽）不适用。如需精确，应实现 IEC 60534-2-1 Mod 1/Mod 2 闪蒸流计算或引入专门的两相流模型。

8. 气体气动噪音预测¶

源码：[noise.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/noise.py) predict_gas_noise (L69-171) 标准：IEC 60534-8-3

8.1 五步法流程¶

步骤1: 等熵膨胀至阀后 → 求T2, ρ2, c2
步骤2: 阀后流速与马赫数
步骤3: 喉部射流机械功率
步骤4: 声效率 → 声功率 → 内部声功率级
步骤5: 管壁传声损失 + 距离衰减 + A计权 → 外部声压级

8.2 步骤1：等熵膨胀（[noise.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/noise.py) L92-99）¶

R = 8314 / M                       [J/(kg·K)]
T1 = t1 + 273.15                   [K]
T2 = T1 × (P2/P1)^((γ-1)/γ)       [K]   等熵膨胀
ρ2 = P2 × M / (8.314 × T2)        [kg/m³]  理想气体
c2 = √(γ × R × T2)                [m/s]   阀后声速

8.3 步骤2：阀后流速与马赫（[noise.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/noise.py) L102-106）¶

A = π × (D/1000)² / 4              [m²]   管道截面积
ṁ = W / 3600                      [kg/s]
U2 = ṁ / (ρ2 × A)                 [m/s]  阀后流速
Ma2 = U2 / c2                      马赫数

8.4 步骤3：喉部射流机械功率（[noise.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/noise.py) L108-116）¶

U_vc = U2 / FL                     喉部射流速度（用FL关联）
U_vc = min(U_vc, √(γ×R×T1))        不超过声速量级
Pow = ½ × ṁ × U_vc²                [W]    机械功率

8.5 步骤4：声效率与声功率级（[noise.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/noise.py) L118-131）¶

声效率 η（关键系数，见 [NOISE_CFG](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/noise.py) L58-66）：

流态 η 计算式 系数
临界/超临界 (x ≥ Fγ×xT) η = eta_sonic 1.0×10⁻²
亚临界 η = eta_subsonic × Ma^ma_exp 1.2×10⁻³ × Ma^3.5
  • η 限幅 [1×10⁻⁸, 0.5]
Wa = η × Pow                      [W]    声功率
L_Wi = 10 × log10(Wa / W_ref)     [dB]   内部声功率级
W_ref = 1×10⁻¹² W

8.6 步骤5：峰值频率与传声损失（[noise.py](file:///d:/KELK办公/信息化工作/207 自研系统/KELKCalCv/backend/app/calc/noise.py) L133-152）¶

峰值频率：

d_vc = 0.6 × D                    [mm]   喉部直径近似（0.6倍管径）
f_p = St × U_vc / (d_vc/1000)     [Hz]   St=0.20（斯特鲁哈尔数）

管壁传声损失（钢制圆管简化）：

f_r = c2 / (π × d_i)              [Hz]   环频
m'' = ρ_steel × t                 [kg/m²] 面密度（ρ_steel=7850, t=壁厚m）
z_g = ρ2 × c2                     [Pa·s/m] 气体声阻抗
ratio = (m'' × 2π × f_p) / z_g
TL = 10×log10(1 + ratio²) + 10×log10(m'' / (z_g × d_i))
TL = max(TL, tl_floor)            tl_floor=6.0 dB

rad = 10 × log10(d_i / (4 × r))   [dB]   距离辐射项（r=测点距离m）

12.4 气体气动噪音预测差异（重点）¶

Noise 页签核心部分 R128-R186 构成 5 区段判定 + 2 级声音传播模型，当前系统为简化单峰模型：

12.4.1 压力区域分段（Excel R158 五区模型，已按 E 列精确公式核对）

中间压力参数（统一单位 barA，再入库按 ×100 → kPa(abs)）：

  • R143 P1' (Pn)：CHOOSE(OptPn, P1, GasCvP1 迭代反推)；OptPn 从 valve_sizing_indices.opt_pn 读取（1=直取 P1，2=涡轮旁路迭代）。
  • R152 Pvc（喉部静压，区段 1/2）：P1' - (P1' - P2) / (FLp/Fp)² — 注意：分母是 (FLp/Fp)² 而非 FLp²（R97 = FLp/Fp）。
  • R153 Pvc_crit（临界喉部压力，区段 3/4/5）：P1' · (2/(k+1))^(k/(k-1)) （等熵临界声速状态）。
  • R154 P2C（区段1↔2分界，P2_crit）：P1' - (FLp/Fp)² · (P1' - Pvc_crit)。
  • R155 α：Pvc_crit / P2C（2-3 区膨胀比，后续 fp 使用）。
  • R156 P2B（区段2↔3↔4分界，Breakpoint）：P1' / α · (1/k)^(k/(k-1))。
  • R157 P2CE（区段4↔5分界，恒声效起点）：P1' / (22 · α)。

区段判定（R158）：Regime = IF(P2 > P2C, 1, IF(P2 > Pvc_crit, 2, IF(P2 > P2B, 3, IF(P2 > P2CE, 4, 5))))。

12.4.2 喉部马赫、自由膨胀马赫、峰值频率（Excel R159/R167/R169/R178 精确式）

  • R159 Uvc（m/s，区段1/2实际喉部速度）：Uvc = √( 2·k/(k-1) · (1-(Pvc/P1')^((k-1)/k)) · P1'×10⁵ / ρ1' )。P1' 单位 bar → ×10⁵ 转 Pa；ρ1' 单位 kg/m³。
  • R167 Uvc_crit_sat（m/s，临界声速喉部，区段 2~5）：√( 2·k/(k+1) · P1'×10⁵ / ρ1' )，即等熵膨胀至 M=1 对应的动能速度。
  • R162 c_vc 喉部声速：√(10⁵·k·P1/ρ1)（进口声速近似）。Ma_vc = Uvc / c_vc（R163）。
  • R169 Mj（自由射流马赫，区段 2~5 核心量）：√( 2/(k-1) · ( MIN(22, P1'/(α·P2))^((k-1)/k) - 1 ) )。当 P1'/(α·P2) ≥ 22 时，Excel 强行按 22 封顶（限制膨胀上限），避免 Mj 异常放大。此为实现关键。
  • R178 fp（峰值频率 Hz）= CHOOSE(Reg, Ma_vc·c1, Mj·Uvc_crit_sat, Mj·Uvc_crit_sat, 1.4·Uvc_crit_sat/√(Mj²-1), 1.4·Uvc_crit_sat/√(Mj²-1)) × Stp / Dj；Dj（R151）= 4.9e-3 · FD · √(Cv · (FLp/Fp)) （单位 m）。Stp 从 valve_sizing_indices.stp 读取。
  • 当前引擎：U_vc ≈ U2 / FL 并被声速上限截断；f_p ≈ 0.2·U_vc / (0.6·D) — 均与 Excel 能量守恒式、5 区段 CHOOSE 不符，导致 Uvc/Mj/fp 估计系统性偏差。P0：按上述精确式替换。

12.4.3 声功率级 → 外部声压级（Excel R176/R179/R180/R181/R186）

Excel 的 5 步外部声压级传播：

  1. R177 声功率 Wa (W) = IF(Reg=1,Wm,Wms) · 10^Aeta · CHOOSE(Reg, η因子) — 详见 12.4.1。
  2. R176 Ma 修正 Lg (dB)：16 · log10( 1/(1 - MIN(M2, 0.3)) )，M2 为出口马赫（R175=Up/c2）；当 M2 ≥ 0.3 时修正封顶 16·log10(1/0.7) ≈ 1.5 dB。
  3. R179 EarlyAdder (dB)：ValveData OptPn=2（涡轮旁路型），若多级降压 StgNeeded≥2 则附加 dB，否则为 0；常规阀 (OptPn=1) 恒为 0。
  4. R180 内部声压级 Lpi (dB) = 10·log10( 3.2×10⁹ · Wa · ρ2 · c2 / D_ID(m)² ) + Lg + EarlyAdder。3.2×10⁹ 为 VAX 风格声强→声压级常数（IEC 典型值 4ρc/π≈ 4·1.2·340/3.14≈520；此处 3.2e9 为 W→p² 的内建尺度，不建议随意改动）。
  5. 管壁传声损失（R181~R184）→ NoiseLpe1m(D_ID_m, D_Thk_m, ρ2, c2, fpeak, Lpi, PDamp, fRing, fCi, fCe) 黑盒函数（R186 直接调用）。
    其中 R181 PDamp（管径阻尼）：D>0.15m 时 0dB，D<0.05m 时 +9dB，中间 -16660·D³；R182 RingFreq=5000/(π·D)；R183/R184 为内/外吻合频率。
