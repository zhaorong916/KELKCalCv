## 一、核对方法

1. PDF 为唯一权威数据源。p1/p2/p23/p24 有文字层（`pdfplumber` 坐标化提取），p3~p22 全部文字转曲（`pypdfium2` 渲染 PNG 图像识别）。
2. docx 28 表全部由 OCR 重建，逐格与 PDF 比对：一致采信；不一致以 PDF 为准并更正；docx 缺漏内容按 PDF 补入。
3. 页号换算：PDF 页 = 印刷页 + 2（印刷页 1 对应 PDF p3）。
4. 高密度表（表3 额定Cv、表4-1/4-2 允许压差、p15~p22 尺寸表）在临时目录用 PIL 裁剪放大 1.9~2.0 倍逐格复核（`gv120_crop/`）；docx 中 >4 位连续数字一律视为粘连高危回图像重提。
5. docx 正文段落（python-docx 提取 649 段）用于核查表外脚注、图例、注意事项及未被表格化的页面数据。

## 三、逐表核对结论

### 数值完全一致（采信 docx，无需改动）
- 表0/1/2（阀体、上阀盖、阀内件）、表3（执行机构）、表4（控制附件）、表5（特殊规格）、表6（表1-1 PARTS LIST 20项）、表7（表2-1 碳钢材质组合）、表8（表2-2 不锈钢材质组合）。

- 表24~27（附表一 ANSI 18行温压、附表一 JB/PN 温压、附表二 公称压力对照、附表三 常用材质对照）与 PDF 文字层**逐格一致**。
- p15 正作用 PD3000LA-D 尺寸表 docx 未表格化，但以段落文本（第195-541段）完整存在，逐值与 PDF 一致。

### PDF 确认的特殊事实
- **p19 与 p20（306SLA 正/反作用）数值在 PDF 上完全相同**（H1/H3/H4 一致），与 GC320 同规律；docx 漏 p20 表，但数据可知。
- **p21 与 p22（306LLA 正/反作用）同理完全相同**。
- p15 与 p16（PD3000LA 正/反作用）H1 与 L2 区间不同（如 1/2"/3021LA：正作用 H1=430/530、L2=133~113；反作用 H1=470/570、L2=113~133），系真实差异。
- 306SLA/306LLA 表含 H3/H4 列（标准型/散热片型上阀盖的执行机构及手轮高度），替代 L1/L2/W 列。
- 表4-1/4-2 阀芯列序为：1/8~3/8、1/2、3/4、1、1-1/4、1-1/2、2、2-1/2、3、4、5、6、8（小口径 1/8~3/8 合并为一列）。
- **本样本无气缸式执行机构允许压差表**：表4说明明确「配电动/气缸式执行机构最大允许压差请向工厂咨询」（docx 段落172-177 有此说明）。
