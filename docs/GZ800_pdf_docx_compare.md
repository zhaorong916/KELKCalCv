## 一、核对方法

1. PDF 为唯一权威数据源；仅 p1/p2/p34/p35 有文字层（pdfplumber 坐标化提取），p3~p33 全部文字转曲（pypdfium2 渲染 PNG 图像识别，高密度表用 PIL 裁剪放大 1.8~2 倍重读）。
2. docx 41 表全部由 OCR 重建，逐格与 PDF 比对：一致采信；不一致以 PDF 为准并更正；docx 缺漏内容按 PDF 补入。
3. 页码换算：PDF 页 = 印刷页 + 2（已逐页验证成立）。
