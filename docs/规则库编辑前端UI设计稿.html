选型规则库编辑界面设计稿

面向规则维护人员的后台工作台：以「筛选—浏览—编辑」为主线，把规则的编号、类别、系列、动作与条件结构 暴露在同一视线高度，让每一次改动都能被追溯、被校验、被复用。

00

设计基调

这是一套面向工程人员的规则维护界面，视觉优先级是「准确 > 密度 > 装饰」。整体沿用系统既有的 Element Plus 蓝与中性灰，不引入新品牌色；所有辨识度来自信息组织的秩序感，而不是额外的视觉噪音。

三条设计主张

  • 编号即身份：规则编号全程等宽字体、蓝色高亮，出现在列表与弹窗同一位置，不可编辑。
  • 结构先于文案：条件用「字段 + 算子 + 值」三段式呈现，比任何一句自然语言都更容易核对。
  • 校验前置：错误出现在提交点上方，说明缺什么、改哪里，不关闭弹窗、不清空输入。

信息密度

  • 列表行高 42px，表头 38px，一屏可见 12–14 条规则。
  • 弹窗一行两组字段，双列网格，减少纵向滚动。
  • 辅助信息一律 11.5–12px 灰色，不与主数据争视线。

与既有界面的关系

  • 页面容器、筛选条、统计区完全复用 page-card / section-footer 语义。
  • 不新增页面、不新增基础组件，仅在 SelectionRules.vue 内扩展 scoped 样式。
  • 颜色语义沿用系统：蓝=操作、绿=通过、橙=提醒、红=阻断。

条件行录入

条件行是「不用写 JSON 也能精确表达条件」的路径。每行三段：字段 → 算子 → 值。 字段下拉按数值 / 枚举 / 布尔分组；同一物理量的等值、下限、上限键用中文后缀区分， 既避免同名校验混淆，也让维护人员一眼看出比较方向。

i
为什么必须加后缀。后端用 temp / temp_min / temp_max 三个键表达 同一物理量的等值、下限、上限。若下拉只显示「设计温度」三次，维护人员无法判断自己选的是哪一个。 因此显示层追加「（下限）」「（上限）」「（要求）」，而 label 本身保持不变， 规则预览文案仍是干净的「设计温度」。

校验顺序

① 必填项 规则名称 / 类别 / 动作 → 「缺少必填项：a、b」合并一条 ② 条件行 仅 rows 模式先强制同步 → rows_error 非空即阻断 ③ JSON 必须为对象，语法合法 → 「条件表达式 不是合法 JSON：…」 ④ 提交 create 全量 → 后端生成编号 edit 剔除 rule_code

文案规范

  • 按钮用动词：新建规则 / 编辑 / 删除 / 保存 / 同步到 JSON。
  • 错误说「哪里错 + 怎么改」，不只说「校验失败」。
  • 成功提示带对象：规则已新增 / 规则已更新 / 规则已停用。
  • 不使用感叹号与情绪词，保持工程口吻。

交互与校验规范

以下规则为验收依据，实现与设计如有冲突以本节为准。

对象触发结果
规则编号新建 / 编辑始终禁用。新建时 placeholder 随类别与系列实时变化；编辑时展示真实编号，不参与提交校验。
类别变更自动写入默认优先级 10 / 20 / 30 / 40；新建态下编号预览前缀同步切换。
辅助录入切换模式三选一互斥；切到条件行时从当前 JSON 反解析为行，失败则给一条空行。
自然语言本地解析零网络请求，回填系列、类别、动作、条件、条件行与预览；仅当名称为空才填建议名称。
自然语言AI 解析按钮 loading；失败自动回退本地并追加警告；编辑态不回写类别。
条件行字段 / 算子 / 值变更即时调用 rowsToCondition 写回 JSON；错误写入行内提示。
条件行删除行移除后立即重新同步 JSON；至少保留一行空行以便继续录入。
JSON 区格式化仅美化缩进；解析失败只提示，不修改原文本。
保存点击按 06 校验顺序执行；成功后关闭弹窗、刷新列表、提示；失败保持弹窗。

筛选任一条件变化纯前端即时过滤，统计区同步更新匹配数；重置清空全部条件。
07

无障碍与响应式

后台工具同样需要键盘可用与清晰焦点，尤其是在密集录入场景。

键盘与焦点

  • Tab 顺序：筛选条 → 表格操作 → 弹窗字段，弹窗打开后焦点进入首个可编辑字段。
  • 焦点环：2px 主色描边 + 1px 外扩，任何控件在聚焦时都可见，不依赖颜色填充。
  • Esc 关闭弹窗；确认框 Esc 等价取消。
  • 展开行可用 Enter 触发，避免只支持鼠标点击的小三角。

对比与语义

  • 正文 #303133 对白底 ≥ 12:1；次要 #909399 仅用于非关键信息，均 ≥ 4.5:1。
  • 类别与动作不只靠颜色区分，标签内始终有文字。
  • 错误提示带 role="alert"，切换时读屏可播报。
  • 编号字段禁用但保留可读文本，便于读屏读取当前值。

响应式

  • ≥1440：完整 10 列表格，操作列右固定。
  • 1280–1439：来源列收窄至 140，关键词输入 160。
  • ≤1180：弹窗改为 width: calc(100vw - 32px)，双列表单退化为单列。
  • 触屏：行高提升到 48，文字按钮点击区扩至 32×32。
